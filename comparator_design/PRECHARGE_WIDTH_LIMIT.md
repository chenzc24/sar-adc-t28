# M3/M5最小宽度核对

**现有W=100nm已到当前安装PDK模型在L=30nm时支持的下界，没有可继续缩小的模型内扫描点。此次没有新仿真，也没有修改电路或时钟。**

核对对象是A4候选的`pch_mac`，M3/M5均W=100nm、L=30nm、nf=1、multi=1；M2/M4保持multi=4。读取实际TB模型引用及安装源文件，保存文件SHA和派生区间，不保存PDK正文。

| 项目 | 核对结果 |
|---|---|
| 实际模型包装文件 | crn28ull_1d8_elk_v1d8_2p2_shrink0d9_embedded_usage.scs |
| 引用核心模型 | cln28ull_1d8_elk_v1d8_3.scs |
| 原生Spectre日志scalefactor | 0.9 |
| 网表L=30nm对应模型长度 | 27nm |
| 该长度下最窄pch bin | pch.28，模型W范围90–270nm |
| 换算网表W下界，nf=1 | **100nm** |
| 现有M3/M5 | 正好位于下界 |

网表W=90/80/75/60/50nm分别缩放至81/72/67.5/54/45nm，全部低于90nm模型下界。因此用户授权的“如果还能缩小就扫描”条件未满足，不运行域外候选、不使用小于1的multi冒充可制造器件，也不重跑已有100nm结果。

这是**当前模型适用范围**的结论，不是独立的PCell参数校验或版图DRC签核。器件回调/PCell实现为加密内容，未解码；没有把模型bin等同为全部制造规则。即使其他物理规则另有下界，本次模型链也不支持上述更小宽度作为受支持设计点。

既有FF0.99V125°C比较仍有效：M3/M5有效并联宽度0.1/0.2/0.4µm时，启动上冲分别8.753/16.351/37.941mV，复位上冲8.908/10.852/16.696mV，判决113.0/115.5/120.2ps。维持100nm对照；端压问题仍未修复。详见[原扫描报告](PRECHARGE_A4B124.md)。

后续需从其他变量寻找办法。加长L不等于直接减小栅漏重叠电容，还会改变关断电荷和预充恢复；如继续尺寸实验，应作为独立假设检验。本轮没有擅自变更L、器件类型、拓扑或时钟。
