# 8-bit 指标与设计流程

本页定义目标和验证方法；实测值放在 [[Result]]，已采用电路见 [[Head]]。

## 1. 系统目标

| 项目 | 目标或约定 |
| --- | --- |
| 工艺与架构 | T28，全差分、8-bit flat CDAC、顶板采样、异步 SAR |
| 采样率 | 10 MS/s，100 ns/帧 |
| 电源与参考 | VDD=0.9 V，VREFP/VREFN=0.9/0 V |
| 输入 | 共模 0.45 V；差分范围 −0.9～＋0.9 V |
| 时间预算 | 获取 40 ns，转换不超过 60 ns |
| 动态性能 | 暂定 ENOB≥7，对应 SNDR≥43.9 dB |
| 静态性能 | 无缺码，最大绝对 DNL/INL≤1 LSB |
| 功耗 | ≤1 mW；尚未完成整机测量 |

当前异步回路按比较完成情况推进，没有固定 5 ns 位周期。早期 200 MHz 位时钟、3 ns 建立＋1.5 ns 比较等参数属于建模和独立模块夹具。

## 2. 从系统目标分配误差

差分满量程跨度为 1.8 V，因此：

$$
LSB=\frac{1.8}{256}=7.03125\ \mathrm{mV},
\qquad 0.25LSB=1.7578125\ \mathrm{mV}
$$

按 −1 dBFS 正弦，输入 RMS≈0.5672 V。采用项目的 ENOB 换算约定：

$$
SNDR_{min}=6.02\times7+1.76=43.9\ \mathrm{dB}
$$

$$
\sigma_{total,max}=\frac{0.5672}{10^{43.9/20}}
\approx3.620\ \mathrm{mV\ RMS}
$$

总上限包含量化误差。以下模块占比是第一版工程分配，后续可根据实测重新平衡。

| 分量 | 初始分配 | 输入等效 RMS |
| --- | --- | ---: |
| 理想量化 | LSB/√12 | 2.0297 mV |
| 采样噪声 | 0.18 LSB | 1.2656 mV |
| 比较器噪声 | 0.18 LSB | 1.2656 mV |
| Reference/开关噪声 | 0.12 LSB | 0.8438 mV |
| 时钟 jitter | 20 ps，4.5 MHz、−1 dBFS | 0.3207 mV |
| 失真与未建模项 | 0.15 LSB 的等效预留 | 1.0547 mV |

按不相关分量做 RSS 估算为 3.0415 mV，投影 ENOB≈7.25。这个估算用于分配预算，不能证明实际失真、参考记忆和噪声彼此独立。

确定性门限另测：采样保持误差、每次比较前的建立误差、比较器系统 offset 各按 0.25 LSB 检查，不把它们直接混入随机噪声 RSS。比较器随机失配的量产良率要求尚未制定。

## 3. 分层设计与验证

| 阶段 | 目的 | 使用的方法 | 进入下一阶段要确认什么 |
| --- | --- | --- | --- |
| 理想算法 | 校验量化、码字和测量方法 | Python 逐位 SAR；ADCToolbox 辅助分析 | 全码映射、理想静态与相干正弦结果正确 |
| 时钟行为级 | 检查采样、八次判决和预算影响 | Verilog-A；在采样/比较事件中抽取噪声 | 时序正确，噪声影响与分配大致一致 |
| 一阶约束 | 给器件设计提供范围 | RC 建立、kT/C、gm/C 再生、jitter 公式 | 时间、Ron、C、gm 的组合可行 |
| 完整电气宏模型 | 检查电荷与模块相互作用 | 显式 flat 电容、有限 Ron 理想开关、参考 R/C、再生比较器宏模型 | 各 bit 的真实节点残差与电荷守恒一致 |
| 器件级模块 | 验证实际器件能力 | T28 Bootstrap、MOM、参考 MOS、StrongARM、CMOS 逻辑 | 获取、建立、判决、应力分别检查 |
| 联合原型 | 暴露接口与历史效应 | 同一顶层接入实际模拟链和原生异步逻辑 | 多帧正常转换，跨帧恢复、残差和端电压合格 |
| 完整验收 | 判断整机是否满足规格 | 阈值搜索、长正弦、功耗、噪声/PVT/MC、版图后仿 | 同一冻结版本满足系统目标 |

SAR 按相位分析；这里的一阶模型提供设计约束，不是整颗 ADC 的统一线性小信号模型。

当前流程先完成 TT 联合问题定位，再补全角落和统计验证。已经暴露的 PVT/失配问题保留为待办。

## 4. 尺寸选择的依据

CDAC 每侧电容为 `(128+64+…+1+dummy)Cu=256Cu`。Cu 越大，热噪声与局部匹配通常更有利，但采样、参考充放电、面积和功耗负担也增加。

一阶约束用于初筛：

$$
|e(t)|=|\Delta V|e^{-t/(R_{total}C)},\qquad
\sigma_{sample,diff}\approx\sqrt{2kT/C_{side}}
$$

主管 W/L 要同时看大信号获取、连续跟踪、关断注入和端电压。参考开关按电容权重配置倍率，再检查整组换轨；比较器尺寸要兼顾失配、再生速度、输入电容及 kickback，不能只追求 gm 或静态增益。

## 5. 测量定义

| 量 | 定义与检查时刻 |
| --- | --- |
| 当前短正弦的采样误差 | SAMPLE 下降 50% 为 tₛ；eₕ=(TOPP−TOPN)(tₛ＋0.6 ns)−Vin,diff(tₛ)，输入取源端 |
| 比较前建立误差 | 实际 TOP 差分减去该次试探码对应的理想电荷残差；在判决前读数 |
| 比较器判决时间 | CLK 上升 50% 至正确极性的输出差分达到 VDD/2；独立夹具目标≤1.5 ns |
| 端电压应力 | 检查各管相关端对的全时域峰值及模型警告；与精度分开判断 |
| ADC 静态/动态 | 静态找真实码边界；动态对完整转换码做相干 FFT |

理想码为 `clip(floor((Vin,diff+0.9)/LSB),0,255)`。转换时 TOP 会随试探码变化，不能始终拿它与原输入直接相减。SAMPLE 命令时刻也不等于精确的物理采样孔径。
