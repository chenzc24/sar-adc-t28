# 设计流程复盘

我们没有沿一条直线从理想模型走到最终 ADC。实际过程是：先做 10-bit 架构和预算，在采样开关上经历多轮诊断，后来按用户给出的拓扑重新落地，再转成 8-bit flat，逐步接上真实电容、比较器和异步控制器。

下面保留失败和纠偏，不把不同测试夹具中的最好数字串成一条“不断变好”的曲线。当前版本和未完成事项见 [[当前设计]]；本页只解释走到这里的原因。

## 1. 先把设计和工具分开

2026-08-30 建立 ADC 独立仓库和远端 `SAR_ADC_T28` 库。bridge 是连接工具，ADC 仓库保存规格、模型和实验记录，远端 OA 才是 Virtuoso 电路本身。

早期 Spectre 不能正常启动时，一度把环境问题理解成 license 不可用。对齐已经能工作的 `t28_io` 启动环境后，真实 Spectre 编译和仿真成功。这个阶段建立的不是电路性能，而是可信的执行路径。

## 2. 理想算法回答“架构和测量有没有错”

起点是 10-bit、10 MS/s、0.9 V、全差分 5＋5 split CDAC。拆分阵列可以减小电容规模，但代价是桥接比例和寄生更敏感。

先用 Python 做逐位 SAR 黄金模型，用 ADCToolbox 辅助静态和频谱分析。这一步检查码字、量化和测量方法，不会自动给出晶体管电路。

随后从 ENOB ≥9 推导总误差上限，再分配采样、比较器、参考与 jitter 的预算。历史 10-bit 的总等效误差上限约 0.905 mV RMS，采样和比较器各分到约 0.316 mV RMS。

经讨论后明确：总上限由系统目标约束，模块占比是初始工程选择，不是 PDK 已经达到的能力。offset、建立误差和随机噪声也不能全部当作独立白噪声相加。

## 3. 加时序，再加预算里的随机误差

Verilog-A 模型把输入采样、逐 bit 判决和最终输出放进时间轴。最初使用理想采样与 200 MHz 位时钟，10-bit 转换约 47.5 ns。

理想 Spectre 动态结果约 60.954 dB SNDR；加入三项事件级随机噪声后约 58.059 dB，与相应 RSS 预测接近。每次采样抽一次采样噪声，每个 bit 抽比较器和参考噪声，而不是在最终数字码上加随机数。

这证明预算在该抽象中能够执行，不证明真实晶体管噪声已满足预算。后来的物理 transient-noise 是另一层验证。

## 4. 一阶模型有用，但不是完整模块

接着表征 T28 单管和 MOM：确认器件端口、CDF、模型调用，读取选定偏置下的 gm、gds、gm/Id、电容等。PDK 提供模型，仿真给出具体尺寸和工作点下的性质。

然后按相位拆成 RC 获取、CDAC/reference 建立、gm/C 再生和采样 jitter 敏感性模型。它们用来给 Ron、电容、gm 和时间预算划可行域。

用户看到几个简单 schematic 后指出：这些还不是完善模块。这个区分很重要。SAR 是开关非线性系统，不能把几个一阶夹具称作完整 ADC 的统一小信号模型。最初测得的 35.6 fF 也只是表征样本，不是最终 Cu。

## 5. 完整电气宏模型，以及一次网表与原理图脱节

完整宏模型加入了显式 5＋5 电容网络、有限 Ron 的理想继电器、参考 R/C、再生比较器宏模型和闭环 VA 控制，开始求解模块之间的电荷与节点相互作用。

六个标称码中心完成约 49.52 ns，最大比较前建立误差约 0.102 LSB。增大参考阻抗、寄生或 kickback 的负例则暴露失败；最终码偶然正确也不能掩盖建立不达标。

这里出现过一个本可避免的问题：本地网表先跑通，Virtuoso schematic 却仍有占位和浮空接口。按用户要求修复 OA 后，重新从保存的原理图导出并仿真，才真正建立对应关系。

此后的网表快速实验仍有价值，但必须标明“网表候选”，不能假装已经更新了 OA。

## 6. 为什么开始做 Bootstrap

普通 transmission gate 在 TT 下可以通过 W/L 扫描满足 Ron，但到低压、冷 SS、中间输入电压时，导通裕量严重不足。继续加宽会同时增加寄生、漏电和时钟负载。

因此先用理想自举栅压筛选真实主开关，再搭实际电荷泵、预充和复位电路。初版曾把三只 NMOS 误搭为 PMOS；原来的 DC 输入又可能让输出在工作点就接近目标。后来重建正确器件，并让输入在开关关断期间翻转，以真正检查动态获取。

## 7. 采样开关上的长迭代：问题不只是 Ron

以下都是历史 10-bit 阶段的结果，测试夹具和改动并不完全相同：

| 尝试 | 观察与转向 |
| --- | --- |
| 初版完整 Bootstrap | 差分保持误差可达 12.026 mV；获取很快不代表保存准确 |
| 增强放电与调整非重叠 | 极端尺寸仍约 9.097 mV；栅极放干净之前主要误差已经发生，停止盲目加宽 |
| 底板采样、理想钳位 | 同一夹具约 0.0079 mV，看到了电荷机制的潜力 |
| 换真实 T28 钳位 | 误差回到约 2.096 mV；理想钳位的成功不能直接继承到器件实现 |
| 改用部分 1.8-V 器件 | 标称过压提醒减少，保持误差仍约 −8.755 mV；耐压和精度要分开解决 |
| 审计 MN9 电流 | 发现约 25.86 µA 的持续输入负载路径，但不能把它当成全部已存储误差的唯一原因 |
| 独立 GMAIN，先关主管再复位 | 复位贡献约 0.080 mV，主要 −2.53 mV 已在关断时形成；仅延迟复位不够 |
| 接完整底板交接 | GMAIN=VIN 不保证换轨后关断，另一端电压改变会引起再导通 |

“拆开栅极”没有取消自举：采样时仍接自举电压，保持时另行关断。真正的难点是这个关断条件要覆盖 CDAC 后续所有节点运动，而不是只看某一时刻的 VGS。

最终主线回到顶板采样。理想隔离、真实互补保持管、局部 PGATE 驱动依次测试，PGATE 版本的五点最坏误差约 0.606 mV。9 月底暂时接受了这一阶段结果，但没有改写原来的 0.439 mV 门槛，也没有宣布剩余理想控制和井结风险已经解决。

## 8. 按用户 Canvas 拓扑重新落地

10 月 19 日不再继续扩建旧方案，而是把用户提供的拓扑映射为原生 T28 1.8-V MOS，用真实两管反相器替代理想反相器。最初偏向自定义封装的理解被纠正，没有沿用那套未被接受的尝试。

单电容测试在获取与注入之间选出主管 W=0.5 µm、L=150 nm。接到同一完整 10-bit split CDAC 后，新方案五点最坏保持误差约 0.394 mV，原未隔离方案约 1.536 mV。

这是两套实际电路的比较，拓扑、器件、电容和内部时序同时不同，不能把改善全部归给主管宽度，更不能称为 T28 相对 Sky130 的工艺优势。

## 9. 改成 8-bit flat，负载必须重新验证

用户选择先做 8-bit，减少桥接和高精度因素。我们重新补齐算法、VA、预算、一阶约束和 flat 电气宏模型，没有简单截掉两位。

新 LSB=7.03125 mV，0.25 LSB=1.7578125 mV。flat 每侧 128…1 加 dummy；沿用原比较 Cu 时负载明显大于旧 split 的有效输入负载。

0.5 µm 主管因此出现约 12.91 mV 获取误差。保留原拓扑，把主管调到 1 µm 后，五点最坏保持误差约 0.126 mV。尺寸不是越小越好，也不能把旧负载的通过结论搬到新阵列。

## 10. CDAC 与比较器逐步器件化

CDAC 选定约 4.004 fF 的 T28 MOM 单元，每侧总容量约 1.025 pF。独立的 512 个单元用于电容失配，名义聚合视图用于加速确定性联合测试。

首轮默认 mismatch 设置没有真的产生电容散布，确认开关生效后才重新统计；“有随机变量计数”并不自动证明匹配分析有效。开关最初按 sqrt(weight) 缩放，随后改为按权重配置倍率，使不同 bit 的 RC 更一致。

真实参考开关可以得到正确码，却在复位和换轨时过压。调整驱动、时序或耐压器件只能解决部分条件；后来用理想栅压拆开诊断，再选 3× pass MOS 进入联合基线，真实栅驱动仍留待后续实现。

StrongARM 从 9 月并行推进。11 管 T28 比较器的标称速度约 191 ps，但随机门限标准差约 12.73 mV，部分低压冷角和负载条件也未通过。按用户要求先集成再优化，不等于这些已知问题已经解决。

## 11. 控制器也做过减法

先有同步逻辑提案，后来转异步，搭出较完整的 26-cell 握手和保护控制器。按用户希望的简单主线，再收敛到 21-cell：采样初始化、本地比较、写入、更新和八位位序循环，不另加 EOC、状态银行和多层流程。

在这一阶段，“真实模拟链＋VA 控制”和“原生控制器＋理想 plant”是两条不同验证线。它们各自能跑，并不等于整机已经接好。

## 12. 合龙后，模块通过的结论不能直接继承

R0 先冻结接口与来源，R1 才把真实采样、MOM、StrongARM 与原生异步控制器接到同一顶层。11 次运行、22 帧码字正确，但出现约 1.267 V 参考管端电压和 1.250 V 比较器输入峰值。

位间参考交接偏斜会在部分底板浮置时引发电荷重分配。“有先断后通”不足以保证整字换轨安全。R2 用理想栅控整字对齐提交，改善了转换尖峰，却没有解决下一采样的参考恢复过冲。

R3 再把恢复等待改成 0.1 ns、栅边沿改成 50 ps。四组两帧标称测试中，参考/比较器所扫端电压峰值约 0.945/0.951 V。但这是理想参考时序边界下的短测，不是真实栅驱动器或全码验收。

## 13. 长测试暴露的是模型程序错误，不是失配

修复前 R3 的长测试出现严重跳码。重放发现某帧采样期间没有恢复中点，关断后才切回，搬动已保持电荷，误差约 −442.85 mV，附近的 64/65 码跳成 1 码。

先怀疑采样边沿识别，但只改边沿仍失败。记录内部状态后才发现：timer 已回调，代码又用近乎严格的绝对时间比较拒绝了约早 0.159 fs 的有效事件，最终漏掉整个获取阶段的恢复。

B 改成由有效 timer 回调推进状态，不改晶体管尺寸和求解精度。相同 12 帧历史中，异常帧恢复到 65 码，保持误差约 +0.101 mV。B 随后同步到 R3 OA，旧模型保留作对照。

这次错误也说明全码长任务启动偏早。多帧、带历史的短测试应先覆盖状态交接，再投入完整性能扫描。

## 14. 连续输入把注意力拉回跟踪带宽

B 的 500 kHz 连续正弦短测完成 24 帧，八位循环正常，没有此前的大幅跳码；但最大采样保持误差 4.465 mV，14/20 个观察点超出预算。

关断前已有同量级误差，不能再把它全叫作关断注入或 BOOT 复位。后处理显示约 1.781 ns 的等效滞后和约 −0.0258% 的增益偏差；扣掉直流和该频点基波后的剩余量约 5.60 µV RMS。

这帮助我们区分相位、增益和非基波成分，却没有让原始预算自动通过。截至本页来源提交，主管宽度 2×/3×的短测已启动，结果尚未成为已审核结论，也没有回填 OA。

回头看，最反复的一课是：**静态台阶最后能建立，不代表连续输入能准确跟踪；最终码正确，不代表内部节点安全；理想边界有用，但必须说清它替电路完成了什么。**
