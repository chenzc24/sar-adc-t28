# 8-bit 设计经验

这里保留可以复用的判断方法；具体版本过程见 [[Revision]]，数据见 [[Result]]。

## 1. 每个结果先说清模型层次

理想算法验证量化；宏模型验证电荷和时序约束；PDK 器件验证实际驱动、寄生与非线性。前端＋宏比较器的 ENOB，不能直接当成真实比较器＋异步逻辑的整机性能。

写结论时至少交代：哪一版电路、哪些部分理想化、输入条件、测量时刻和未覆盖项。见 [[Result#1. 行为级与完整电气宏模型]]、[[Result#2. Bootstrap 与实际 CDAC]]。

## 2. 把“码正确、精度合格、应力合格”分开

最终码正确可能掩盖较大的模拟误差；比较时已经建立，也可能掩盖换轨途中的过压。

因此同时看最终码、判决前残差、全时域端电压。模型检查线用于筛查，不能当作击穿电压或寿命证明。见 [[Result#5. 合龙版本对比]]。

## 3. 静态台阶和连续跟踪都要测

台阶输入最终能建立，不代表正弦斜率最大时能跟上。先用相同输入基准检查关断前误差，再分析关断过程增量，才能判断优化应放在带宽还是切换电荷上。

等效延迟、增益拟合用于解释机制，不自动改变验收采样时刻。见 [[Result#6. 当前 R3＋B 连续正弦]]。

## 4. 尺寸是折衷，改负载就重测

增大 W 通常增强导通，同时改变栅负载、寄生和关断电荷。增大 Cu 有利于热噪声和匹配，却提高充放电需求。

每次尺寸扫描同时检查获取/建立、保持误差、端电压与驱动负担；在同一夹具下比较。见 [[Result#2. Bootstrap 与实际 CDAC]]、[[Result#3. 参考开关与比较器]]。

## 5. 理想替换适合定位，不能代替实现

冷角中只把 Bootstrap 换成理想开关，能隔离采样路径问题；把参考驱动换成理想栅压，能评估驱动影响。替换时保留其他条件，结论才有指向性。

后续要把理想源承担的输出阻抗、边沿同步和驱动电荷逐项落实。见 [[Revision#3. 参考路径从三轨转双轨，再保留理想栅压]]。

## 6. 长仿真前先验证历史与统计是否有效

两帧通过不代表所有跨帧状态正确；MC 运行也不代表目标器件真的随机变化。先检查前导帧、边沿事件、状态复位及实际散布，再投入长统计。

网表候选、已保存 OA、实际仿真输入要分别标明。只有导出与来源核对一致，结果才能归到那个原理图版本。见 [[Revision#2. 从理想电容转到真实 MOM]]、[[Revision#6. 长历史异常来自事件模型]]。
