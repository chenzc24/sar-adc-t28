## Overall
### 1） 系统目标

| 项目    | 目标或约定                          |
| ----- | ------------------------------ |
| 工艺与架构 | T28，全差分、8-bit CDAC、顶板采样、异步 SAR |
| 采样率   | 10 MS/s，100 ns/帧               |
| 电源与参考 | VDD=0.9 V，VREFP/VREFN=0.9/0 V  |
| 输入    | 共模 0.45 V；差分范围 −0.9～＋0.9 V     |
| 时间预算  | 获取 40 ns，转换不超过 60 ns           |
| 动态性能  | 暂定 ENOB≥7，对应 SNDR≥43.9 dB      |
| 静态性能  | 无缺码，最大绝对 DNL/INL≤1 LSB         |
| 功耗    | ≤1 mW；尚未完成整机测量                 |

### 2） 从系统目标分配误差（第一版工程分配）

| 分量             | 初始分配                  |  输入等效 RMS |
| -------------- | --------------------- | --------: |
| 理想量化           | LSB/√12               | 2.0297 mV |
| 采样噪声           | 0.18 LSB              | 1.2656 mV |
| 比较器噪声          | 0.18 LSB              | 1.2656 mV |
| Reference/开关噪声 | 0.12 LSB              | 0.8438 mV |
| 时钟 jitter      | 20 ps，4.5 MHz、−1 dBFS | 0.3207 mV |
| 失真与未建模项        | 0.15 LSB 的等效预留        | 1.0547 mV |

## 3. SAR Logic 设计

两版均为 T28 CMOS 控制器＋理想模拟测试台。TT／0.9 V／27°C，差分输入＋0.123 V。

**AI旧版多层确认与保护：** 加入**判决确认、复位确认、超时和独立输出锁存，保护上一帧结果**，但增加了等待与跨帧状态。SS／0.81 V／125°C 下，截止前仅完成 7 位。

![[assets/sar_logic_compare/old_one_cycle.png|640]]

**纠偏新版简化位循环：** 按“比较→写入→推进／复位→建立等待”循环，八位完成后自然停止。

![[assets/sar_logic_compare/new_one_cycle.png|640]]

| 实现规模 | 旧版 | 新版 |
| --- | ---: | ---: |
| 原生 cell 种类 | 26 | 21 |
| 展开 MOS 数 | 1742 | 1476 |

新版 13 项有界测试的功能／时序检查通过；==FF角应力仍未通过，比较器卡住时可能留下部分码。==

**观察** ：
- Coding这套工作流/项目管理模式让AI有相当的惯性？（他设计第一版时序跟我提了了一大堆握手、确认、提交……）
- AI在SAR逻辑的设计上还是相对擅长：尽管首次过于复杂（或许多搞几次就能出来）。使用了我还没学的bidirectional切换，自己搞对了。

## 5. 用短测与过程监控尽早发现问题

**观察：** AI 可以轮询检查仿真日志、波形和码字，通过短测或长仿真过程监控提前暴露异常，减少无效计算。

**本次例子：** 12 帧重放定位到**理想参考栅控模型的代码问题**，时间判断过严，漏执行 timer 恢复事件，导致错码。**这部分栅控逻辑尚未实现管级电路**（中间出现了问题，稍微交互一下，AI直接换成理想的了……理论上来说应该在SAR逻辑中，还得回去调整。<-- **由于不熟练，并行设计几个子模块出了问题**）

![[assets/wrapup_timer/timer_restore.png|1000]]

*同一电路与输入历史，仅修复模型事件处理：第 9 帧输出由 1 码恢复为预期的 65 码。*

## 6.总结
- 配合一些知识，GPT-6.1 sol xhigh能完成这个8bit SAR ADC到晶体管级设计。（对于一个确定工作的**初学审核者**也需要这部分知识）
- AI擅长使用工具，以及数值计算（全程几乎没有碰Virtuoso，或许这部分学习成本可以省）
- 相比于系统设计，AI更擅长调参/试错？（全程没管W/L、gm/ID、容值等等各种参数的设定，只是偶尔提醒几句。不知道多大程度上造成了问题/也可能是这个电路不敏感，但看起来勉强能工作）
- 确定工作流/审核可以配一些知识，但**Research没法配知识**……（多放几个Agent出去踩坑？）
