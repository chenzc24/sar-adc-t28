# 8-bit 全码性能与 ADCToolbox 分析

空闲段分步复位版保持了原 R4 的静态与动态性能，本批次参考开关 CMI 告警由 4 个案例降为 0 个。输出残差接近理想量化水平，尚不是整机全条件验收。

## 测试条件与版本

| 项目 | 条件 |
| --- | --- |
| 电路 | T28 管级 ADC；参考分步复位移到上一轮转换后的空闲段，恢复采样窗口，采样关闭沿不变 |
| 工况 | TT，VDD 0.9 V，27°C，10 MS/s |
| 理想部分 | 外部电源、参考电压源、SAMPLE 激励；输入每侧 50 Ω，参考每轨 50 Ω＋4 pF |
| 静态测试 | 255 个转换边界、256 个码中心；二分搜索区间 1/128 LSB |
| 动态测试 | 4 帧预热＋1024 点，4.501953125 MHz，−1 dBFS，相干矩形窗 FFT |
| 本轮不包含 | 瞬态噪声、PVT 扫描、失配、PEX、功耗验收 |

9 个案例、3618 帧完成；逐帧控制与码字校验通过。候选为网表实验，未替换原 R4 或 Virtuoso OA 基线。每帧 98 ns 读取码字，此时参考已复位，顶板电压不再代表转换末残差。

## 与原 R4 对比

| 指标 | 原 R4 | 空闲段复位版 |
| --- | ---: | ---: |
| DNL 范围／LSB | ±0.02344 | ±0.02344 |
| 最大端点 INL／LSB | 0.02103 | 0.02103 |
| SNDR／dB | 48.729 | 48.760 |
| ENOB／bit | 7.802 | 7.807 |
| SFDR／dB | 65.593 | 65.154 |
| 有 CMI 告警的案例 | 4/9 | 0/9 |

静态线性度基本不变，SNDR 基本持平，SFDR 略降；不是所有指标都改善。56/1024 个正弦码字不同，差值均不超过 1 码。

## 十二张图怎么看

![[assets/idle_performance/toolbox_panel.png|1400]]

ADCToolbox 0.9.1。图号从左到右、从上到下。多数图的残差定义为：

$$e[n]=V_{code}[n]-V_{fit}[n]$$

即输出码中心电压减拟合正弦；拟合吸收固定增益、相位和 DC，不是直接减时钟沿的真实输入。以下“噪声”不能当作实测晶体管热噪声。

### 第一行

**① 输出频谱**：横轴频率，纵轴相对基波功率 dBc。看总体 SNDR 和最大杂散；本轮最大杂散在 4.16992 MHz、−65.154 dBc，不能仅凭频率认定其电路来源。

**② FFT 幅相图**：每点代表一个频率分量；半径表示强弱，角度表示相对于记录起点的相位。顶部 0°，顺时针增加。基波在最外圈约 **262°**，不是 ADC 引入了 262° 相移。

**③ 残差随电平**：蓝点是逐点残差，红线是 32 桶平均。红线整体靠近零，没有很强的电平相关弯曲；它是分桶诊断，不能替代静态 INL/DNL。

**④ 残差 RMS 随相位**：看正弦不同位置的误差强度。大部分接近理想量化的 0.289 LSB；局部凸起不等于 jitter。AM/PM 分桶趋势拟合 R² 约 0.22，不足以可靠归因；图中仅展示 RMS，不是完整 AM/PM 分解。

### 第二行

**⑤ 时域谐波分解**：蓝线为总残差，红线为 H2–H5。总残差 2.068 mV RMS，H2–H5 仅 0.167 mV RMS，因此低阶失真不是主要成分；剩余部分仍包含量化和其他杂散。

**⑥ 谐波相对相位**：仅画基波和谐波，以基波为相位参照。长度表示谐波大小，角度表示叠加关系；本轮 H3、H5 可见，H2、H4 低于显示下限。不能单凭角度区分开关、CDAC 或比较器失真。

**⑦ 残差分布**：蓝线为 KDE 概率密度，红线为高斯对照，绿线为理想均匀量化。当前更接近平顶的量化分布；RMS 0.294 LSB，接近理想 0.289 LSB。平滑估计会使边缘出现拖尾。

**⑧ 残差自相关**：横轴为间隔样本数，零延迟的 1 是归一化定义。其他位置最大绝对值约 0.156，存在一定结构；相干量化本身也可相关，不能直接叫上一拍残留。

### 第三行

**⑨ 残差频谱**：去掉拟合基波后看剩余频率成分。单位 dBFS，以 ADC 满量程为参考；不同于①的 dBc。用于找可疑频率，不直接定位器件。

**⑩ 残差包络频谱**：先取 `abs(Hilbert(e))`，再做 FFT，检查误差大小是否周期性变化。峰值可提示调制，也可能来自量化或拍频，不是参考纹波的直接测量。

**⑪ 延迟样本平面**：画 x[n] 对 x[n+k]；本轮自动选 k=5，正弦形成近似圆形。算法未检出离群点，说明本记录没有明显异常码，不等于比较器永不亚稳。

**⑫ 上升／下降趋势**：按离散数据梯度分组后拟合残差。U 形、S 形、两线分离可分别提示二阶、三阶失真或记忆效应。本轮平均分离仅 68 µV，约 0.0097 LSB，不作为实际迟滞测量。

## 两张相位图的区别

②问“开始录制时，各条波走到哪里”；⑥问“谐波相对基波如何叠加”。

对第 h 次谐波，⑥按工具箱约定消除记录起点影响：

$$\theta_h=\phi_h-h\phi_1$$

| 示例 | 基波相位 | 三次谐波相位 | 相对相位 |
| --- | ---: | ---: | ---: |
| 原记录 | 20° | 80° | 80°−3×20°＝20° |
| 起点向后移动 | 50° | 170° | 170°−3×50°＝20° |

电路没变，②的点转了，⑥的相对角度没变。相同幅度的三次谐波，反相叠加与同相叠加会造成不同波形；普通幅度谱看不出这一差别。

本轮②基波为 **−98.004°，等价于 261.996°**。输入—输出拟合相位差却是 **−2.862°**：前者参考记录起点，后者比较输入与输出，两者不矛盾。谐波很弱时，不宜过度解读角度。

## 时域拟合与读码时刻

![[assets/idle_performance/time_fit.png|1000]]

从上到下：

1. 输入、输出拟合正弦、输出采样点；码字关联回内部 SAMPLE_INT 下降沿。
2. 按每帧 98 ns 读码显示阶梯，比内部时钟沿晚 56.92 ns；这是读取延迟，不是转换耗时。阶梯也不代表真实总线全程不变。
3. 输出减拟合正弦：**2.068 mV RMS，峰值 3.622 mV**，阴影是 ±0.5 LSB 量化参考。
4. 输出减时钟沿输入：**28.402 mV RMS，峰值 43.351 mV**，大部分可由固定相位／增益／DC 分量解释，不能笼统叫保持误差。

拟合幅度差 −0.0540%，相位 −2.862°，本频点等效滞后 1.766 ns。内部时钟沿不是校准后的物理采样孔径，前端频率响应也会贡献相位，因此不能把 1.766 ns 直接认定为 Bootstrap 延迟。拟合用于诊断，没有校准或修改输出码。

![[assets/idle_performance/toolbox_phase_fold.png|900]]

*全部 1024 点按输入相位折叠到一个周期。输入接近 Nyquist，每周期仅约 2.22 个点；这张图便于观察形状，但不是连续时序。*

## 结论与依据

当前名义条件下，残差接近量化主导，低阶失真较小，没有明显离群码；静态与动态指标保持，原生过压告警在本批次消失。噪声、PVT、失配及全节点可靠性仍须独立验证。
