# 8-bit 全码性能与 ADCToolbox 分析

本文记录（`027b951`） 的 TT 结果：全码无缺码，SNDR **48.760 dB**，ENOB **7.807 bit**。
## 版本与测试条件

参考开关在上一轮转换后的空闲段分步复位，恢复采样窗口，采样关闭沿不变。

| 项目    | 条件                                             |
| ----- | ---------------------------------------------- |
| 工况    | T28，TT，0.9 V，27°C，10 MS/s                      |
| 激励与负载 | 理想外部电源、参考源和 SAMPLE；输入每侧 50 Ω，参考每轨 50 Ω＋4 pF    |
| 静态    | 255 个转换边界、256 个码中心；二分搜索区间 1/128 LSB            |
| 动态    | 4 帧预热＋1024 点；4.501953125 MHz，−1 dBFS；相干矩形窗 FFT |
| 验证范围  | 9 个案例、3618 帧，逐帧控制与码字校验通过                       |
| 未包含   | 瞬态噪声、PVT 扫描、失配、PEX、功耗验收                        |

### ADCToolbox 重新计算 DNL / INL

这次直接把该版本的 **1024 个整数正弦输出码**送入 `analyze_inl_from_sine(num_bits=8, clip_percent=0.01)`，由工具箱执行直方图统计、正弦 CDF 反演、DNL 归一化及 INL 累加。没有使用已有的 DNL/INL 数组作为输入。

![[assets/idle_performance/static_sine_reanalysis.png|900]]

| 正弦直方图重算 | 实际 ADC 输出 | 理想量化器合成对照 |
| --- | ---: | ---: |
| DNL 最小值／LSB | −0.31323 | −0.31364 |
| DNL 最大值／LSB | +0.27498 | +0.27958 |
| 最大 INL 绝对值／LSB | 0.17024 | 0.17664 |

**这是一份短记录诊断，不是全码静态验收。** −1 dBFS 输入只覆盖码 13～242，1024 点平均每个已覆盖码约 4.45 点，且正弦各码的出现次数不均匀。1% 的边缘裁剪也限制了最终分析范围。图中理想量化器使用相同采样长度、相干频率及由输出拟合的正弦幅相，是算法对照，不是另一组电路仿真；它也出现接近的起伏，表明有限相位采样与直方图估计误差不可忽略，不能把重算曲线全部归因于 ADC 非线性。

以上 INL 是工具箱归一化 DNL 的累加结果，与下方边界搜索的端点 INL 口径不同。曲线未平滑，横轴保留工具箱返回的码索引。完整数组、输入哈希与算法实现哈希见[重算记录](../../verification/sar8_idle_performance/reanalysis_20261028.json)。

### 边界搜索结果：保留用于对照

**方法：转换边界二分搜索。** 对 255 个边界分别搜索，取最终区间中点计算码宽和边界误差；搜索区间宽度为 **1/128 LSB = 0.0078125 LSB ≈ 54.93 µV**，其中标称 LSB = 1.8 V/256 = 7.03125 mV。这是搜索分辨率，不是对总测量误差的保证。

![[assets/idle_performance/static_idle.png|900]]

*历史边界搜索放大图，使用 Matplotlib 绘制。从上到下：DNL、端点 INL、raw transition error。对应本节开头性能表的静态指标；DNL 不含两端饱和码宽。这组数据不与上方正弦直方图估计值混用。*

DNL 用标称 LSB 归一化；端点 INL 以首尾边界直线为基准，并用端点跨度得到的 LSB 归一化。Raw transition error 是实际边界相对理想边界的偏差，保留偏置和增益误差。小台阶受边界搜索分辨率影响，不把小于搜索区间的细节解释为确定的电路特征。

要获得独立的工具箱全码静态结论，下一步应对同一冻结网表采集均匀慢斜坡输出，调用 `analyze_inl_from_ramp()`，并用加密采样检查结果收敛。已有二分搜索记录不是均匀斜坡，不能直接用于该算法；重复同一组相干正弦码也不会增加有效相位覆盖。本次仅完成历史数据的真实重分析，未新增电路仿真。

![[assets/idle_performance/spectrum_idle.png|900]]

*ENOB = (SNDR − 1.76)/6.02，未作 −1 dBFS 满幅补偿；输出码未校准。

## 十二图读法

![[assets/idle_performance/toolbox_panel.png|1400]]

采用 ADCToolbox 0.9.1，图号从左到右、从上到下。主要残差定义为输出码中心电压减拟合正弦：

$$e[n]=V_{code}[n]-V_{fit}[n]$$

拟合吸收固定增益、相位和 DC。

| 图 | 看什么 | 本轮结果与解释边界 |
| --- | --- | --- |
| ① 输出频谱 | 相对基波功率，dBc | 最大杂散 4.16992 MHz、−65.154 dBc；频率本身不能定位器件 |
| ② FFT 幅相 | 各频率分量相对记录起点的相位 | 顶部 0°、顺时针；基波约 262°，不是 ADC 输入输出相移 |
| ③ 残差随电平 | 逐点残差与 32 桶平均 | 均值整体接近零；不能替代静态 INL/DNL |
| ④ 残差 RMS 随相位 | 正弦不同位置的误差强度 | 多数接近理想量化 0.289 LSB；AM/PM 趋势拟合 R²≈0.22，不足以归因于抖动；此图不是完整 AM/PM 分解 |
| ⑤ 时域谐波分解 | 总残差与 H2–H5 | 分别为 2.068 mV、0.167 mV RMS；低阶失真占比较小 |
| ⑥ 谐波相对相位 | 谐波相对基波的叠加关系 | H3、H5 可见，H2、H4 低于显示下限；弱谐波角度不宜过度解读 |
| ⑦ 残差分布 | KDE、高斯与均匀量化对照 | RMS 0.294 LSB，接近理想 0.289 LSB；KDE 平滑会产生边缘拖尾 |
| ⑧ 残差自相关 | 不同样本间隔的相关性 | 非零延迟最大绝对值约 0.156；相干量化本身也可能相关 |
| ⑨ 残差频谱 | 去掉拟合基波后的成分，dBFS | 以满量程为参考，与①的 dBc 不同 |
| ⑩ 包络频谱 | `abs(Hilbert(e))` 的 FFT | 可提示周期调制，也可能是量化或拍频；不是参考纹波的直接测量 |
| ⑪ 延迟样本平面 | x[n] 对 x[n+k]，本轮 k=5 | 未检出离群点；不能证明比较器永不亚稳 |
| ⑫ 上升／下降趋势 | 按离散梯度分组的残差拟合 | 平均分离 68 µV≈0.0097 LSB；不作为实际迟滞测量 |

本轮 FFT 基波相位为 −98.004°（等价于 261.996°），输入—输出拟合相位差为 −2.862°。两者参照不同，不能混用。

## 时域拟合与采样时刻

![[assets/idle_performance/time_fit.png|1000]]

从上到下：

1. 输入、输出拟合正弦与输出点；码字关联回内部 SAMPLE_INT 下降沿。
2. 每帧 98 ns 读码的阶梯，比内部时钟沿晚 56.92 ns。这是读取延迟，不是转换耗时；此时参考已复位，顶板电压也不再代表转换末残差。
3. 输出减拟合正弦：**2.068 mV RMS，峰值 3.622 mV**；阴影为 ±0.5 LSB。
4. 输出减时钟沿输入：**28.402 mV RMS，峰值 43.351 mV**；主要包含固定相位、增益和 DC 分量，不能统称为保持误差。

拟合幅度差 −0.0540%，相位差 −2.862°，在本频点等效滞后 1.766 ns。内部时钟沿不是校准后的物理采样孔径，前端频率响应也贡献相位，故不能把它直接认作 Bootstrap 延迟。拟合只用于诊断，未修改输出码。

![[assets/idle_performance/toolbox_phase_fold.png|900]]

*1024 点按输入相位折叠。输入接近 Nyquist，每周期约 2.22 点；此图用于观察波形形状，不是连续时序。*
