# 8-bit 结果与对比

当前采用 **R3＋B，主采样管 1 µm，参考开关 3×**。本页展示各阶段选定实现的结果；迭代原因与历史对照见 [[Revision]]、[[Wrap-up & Experience]]。

8-bit 的 1 LSB＝7.03125 mV，确定性预算为 ±0.25 LSB＝±1.7578125 mV。每张图上方列出测试环境，以及各模块的管级、理想、宏模型或未接入状态。

## 1. 行为级与完整电气宏模型

行为级动态条件：10 MS/s，16384 点、约 4.500122 MHz、−1 dBFS 相干正弦。

| 模型 | 最终结果 |
| --- | --- |
| Python 理想静态 | 256 码／2048 点；无缺码，DNL/INL＝0 |
| Spectre 理想 VA | SNDR 48.746 dB；ENOB 7.805；与 Python 动态码逐码一致 |
| 事件噪声 VA | SNDR 45.883 dB；ENOB 7.329；采样／比较器／参考噪声，无 jitter 注入 |
| 完整电气宏模型 | 10 个标称／边界点通过；最坏建立误差 0.00321 LSB；转换约 39.52 ns |

![[assets/result8_final/01_macro_topplate.png|900]]

*图 1｜电气宏模型：顶板共模、差模及四条独立时序。共模＝(TOPP＋TOPN)/2，差模＝TOPP−TOPN；共模约 0.45 V，差模逐位收敛，最终码 192。纯 VA 行为模型没有物理顶板节点。*

## 2. Bootstrap 与实际 CDAC

### 选定采样开关

T28 1.8-V MOS，主管 W/L＝1 µm/150 nm，Cboot＝1 pF。该阶段每侧 1.756 pF 理想 flat-CDAC 负载，TT／0.9 V／27°C，五个差分输入为 −0.8、−0.4、0、＋0.4、＋0.8 V。

| 五点最大值 | 获取误差 | 保持误差 |
| --- | ---: | ---: |
| 已选 1 µm | 0.0312 mV | 0.1264 mV |

![[assets/result8_final/02_sampling_selected.png|900]]

*图 2｜已选开关的＋0.8 V 代表结果。采样与参考使能分行；保持误差从参考回接完成后开始显示，270 ns 为 −0.1264 mV。*

### 选定 MOM 阵列

T28 `cfmom_2t`，Cu≈4.004 fF，每侧 1.025 pF；512 独立单元用于局部失配统计。

![[assets/result8_final/03_mom_result.png|900]]

*图 3｜200 次局部 MC：每次阵列的最大 |DNL|、|INL| 分布，最坏为 0.10243、0.06555 LSB，200/200 通过内部 0.5 LSB 门限。由 PDK AC 权重计算静态转移，未包含开关瞬态或版图梯度。*

较小实际负载不等于全条件采样通过：首轮 SS／0.81 V／−40°C 满幅翻转，首次保持误差仍为 −27.406 mV。

## 3. 参考开关与比较器

### 已选参考开关

双轨参考采用 **3× pass MOS＋理想栅控**。独立五输入测试中，码、误差和参考管应力检查均通过；最坏参考端电压 0.9828 V，最大比较前误差 0.5216 mV。该夹具使用真实 Bootstrap/MOM、行为控制和理想比较器。

### StrongARM 初始尺寸

| 测试                        | 已测结果                                 | 未通过／未覆盖       |
| ------------------------- | ------------------------------------ | ------------- |
| TT，±0.25 LSB，5 fF/输出      | 判决约 191 ps                           | 仅此条件满足 1.5 ns |
| 27 个 PVT 点，20 fF、双极性      | 46/54 次满足时限                          | 低压／冷角失败       |
| transient-noise，10/30 GHz | 0.652/0.745 mV RMS                   | 带宽未证明收敛       |
| 128 次 MOS 失配              | 门限 σ≈12.73 mV，约 1.81 LSB             | 明显短板；无量产良率结论  |
| 固定中点 CDAC，开／关比较器          | 判决时 kickback≈0.039 mV；全时段峰值≈0.120 mV | 标称小输入，非全部码型   |

![[assets/result8_final/04_comparator_selected.png|900]]

*图 4｜已采用 StrongARM 初始尺寸的标称判决：CLK、OUTP、OUTN、输出差模分行。图示周期约 191.4 ps 达到 VDD/2；PVT 和失配限制保留在表中。*

## 4. 原生异步控制

当前精简实现为 21 种 CMOS cell。13 个有界测试的功能／控制时序检查通过；FF／0.99 V 器件应力仍有告警。

![[assets/result8_final/05_sar_final_timing.png|900]]

*图 5｜一个完整位循环窗口：SAMPLE、CMP_CLK、WRITE、UPDATE 与工作码分行。实际波形共 8 次比较／写入／更新，最终码 145；模拟端口为理想测试模型。*

最终码保留到下一次采样初始化。无独立输出银行或 EOC，比较器卡住时可能留下部分码。

## 5. 合龙版本对比

当前主展示版本为 **R3＋B**，顶层 `sar_adc8_join_r3`，测试台 `tb_sar_adc8_join_r3`。Bootstrap、MOM、参考 pass MOS、StrongARM 和 SAR 为管级；参考栅压、整字提交及外部采样信号仍理想化。

![[assets/result8_final/06_integrated_current.png|900]]

*图 6｜当前整机第 5 帧：顶板共模、差模、采样与三条本地控制信号、最终工作码。红叉为实际比较时刻的理想残差；8 次判决后输出 142，与理想码一致。*

本帧原始保持误差为 **−4.464649 mV**，超过 ±1.7578125 mV 预算；输出码正确仍不足以判定采样精度合格。历史 R1/R2/R3 及 B 修复过程见 [[Revision]]。

## 6. 当前 R3＋B 连续正弦

TT／0.9 V／27°C，500 kHz 差分正弦、峰值 ±0.8 V，10 MS/s；4 帧启动＋20 帧观察。主采样管保持已采用的 1 µm。

![[assets/result8_staircase/sine_staircase.png|900]]

*图 7｜经典正弦／码字阶梯图：灰线为原始差分输入，阶梯由实测最终码按码中心重建，左轴为电压、右轴为码字。上图按采样时刻对齐；下图按帧内 98 ns 的实际读码时刻显示，保留 56.95 ns 读码延迟。*

阶梯的零阶保持用于显示连续读码结果；内部 SAR 工作寄存器仍按原逻辑初始化和逐位更新，没有新增输出保持银行。
