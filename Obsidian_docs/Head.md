# 8-bit SAR ADC 总览

目标是在 T28 上完成一颗 **8-bit、10 MS/s、0.9 V 全差分 SAR ADC**。当前已搭起器件级联合原型，正在解决连续输入的采样误差；整机性能尚未验收。

本笔记库只整理 8-bit 主线。这里记录已核对的版本与结果，不作为仿真任务的实时看板。

## 当前电路

信号路径：**差分输入 → Bootstrap 采样 → flat CDAC 顶板 → StrongARM → SAR 寄存器**。SAR 再控制 CDAC 底板选轨，形成逐位反馈。

| 模块 | 已采用实现 | 主要边界 |
| --- | --- | --- |
| 采样 | 用户 Canvas 拓扑，12 管 T28 1.8-V MOS；主管 W/L=1 µm/150 nm，实际供电 0.9 V | Cboot=1 pF 仍为理想电容 |
| CDAC | T28 MOM，Cu≈4.004 fF；每侧 128…1＋dummy，约 1.025 pF | 联合网表用倍率聚合；512 独立单元用于另行失配测试 |
| 参考选择 | 双轨，高轨 PMOS、低轨 NMOS；P/N 均为 3×方案 | 最终栅压、整字对齐、非交叠仍由理想 VA 实现 |
| 比较器 | 11 管 T28 StrongARM | 初始尺寸，失配与部分 PVT 问题待优化 |
| 控制 | 原生 CMOS 精简异步 SAR | 含理想 R/C 延时；没有独立输出银行和 EOC |

采样采用**顶板采样**。当前双轨阵列通过参考选择字恢复采样初态，没有第三条 VCM 钳位支路；不能把“中点恢复”理解成所有底板直接接到 0.45 V。

外部 SAMPLE、VDD 和输入源是理想激励；输入每侧串联 50 Ω。参考由理想源经每轨 50 Ω、4 pF 网络供给，尚无管级 reference buffer。比较器时钟、写入和更新来自原生异步逻辑，Bootstrap 栅压来自真实自举电路。

## 当前版本与进度

采用版本为 **R3＋B 参考栅控事件修复**，主采样管仍为 1 µm。这是已保存的开发基线，尺寸和性能尚未最终冻结。

- 已完成：8-bit 模型与预算、MOM 选型、模块测试、原生模拟链与异步逻辑合龙。
- 当前问题：连续正弦下采样误差超预算，主要呈现跟踪滞后；参考恢复漏事件已在指定历史中修复。
- 待核对：主管 2×/3×短测尚无完整审核结论，不列为已采用版本。
- 后续缺口：整机静态/动态性能、功耗、噪声/PVT/失配、真实参考驱动与缓冲、版图及后仿。

证据和具体数值见 [[Result#6. 当前 R3＋B 连续正弦]]；下一轮的依据见 [[Revision#7. 从关断误差转向跟踪带宽]]。
