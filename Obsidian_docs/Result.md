# 8-bit 结果与对比

这里只列已核对的 8-bit 证据。不同负载、时钟或模型层次的数字不直接排成性能排名。目标和测量定义见 [[Spec]]，方案选择原因见 [[Revision]]。

## 1. 行为级与完整电气宏模型

行为级动态条件：10 MS/s，16384 点相干正弦，约 4.500122 MHz、−1 dBFS。

| 模型/测试 | 结果 | 说明 |
| --- | --- | --- |
| Python 理想静态 | 256 码、2048 点，无缺码，DNL/INL=0 | 校验算法与测量 |
| Spectre 理想 VA | SNDR=48.746 dB，ENOB=7.805 | 全部动态码与同采样时刻的 Python 一致 |
| 事件噪声 VA | SNDR=45.883 dB，ENOB=7.329 | 注入采样/比较器/参考三项噪声；未注入 jitter、未建模失真 |
| 一阶 RC，200 Ω | 3 ns 残差 0.3514 mV | 每侧比较电容 1.756 pF，最坏 1.8 V 差分台阶 |
| 同一 RC，400 Ω | 残差 25.156 mV，失败 | 证明建立门限能识别慢网络 |
| 完整电气宏模型 | 10 个标称/边界点；最坏建立误差 0.00321 LSB，转换约 39.52 ns | 显式电容＋有限 Ron 理想开关＋宏比较器 |
| 增大参考/开关电阻 | 最坏建立误差 4.408 LSB，失败 | 最终码仍可能正确 |

行为级噪声结果支持初始预算，但不证明真实器件噪声达标。宏模型包含电气节点和电荷重分配，仍不是全管级 ADC。

来源：`docs/eight_bit_flat_migration.md`。

## 2. Bootstrap 与实际 CDAC

### 新负载下的主管尺寸

保留用户拓扑，只改 Mmain 宽度；L=150 nm，TT/0.9 V/27°C。比较夹具每侧为 **1.756 pF**，输入在关断期间翻转，再获取约 40 ns；五个差分目标为 −0.8、−0.4、0、＋0.4、＋0.8 V。

| 主管 W | 最大获取误差 | 最大保持误差 | 判断 |
| --- | ---: | ---: | --- |
| 0.5 µm | 12.910 mV | 12.593 mV | 充放电不足 |
| 1 µm | 0.0312 mV | 0.1264 mV | 该夹具五点通过 1.7578 mV 门限 |

这支持采用 1 µm 初值，不证明连续高频输入也能准确跟踪。

### MOM 器件实现

选定 T28 `cfmom_2t`：Cu≈4.004 fF，每侧 **1.025 pF**。以下来自首轮器件阵列，不等同于后来的 R3＋B 联合版本。

| 测试 | 结果 | 能得出的结论 |
| --- | --- | --- |
| 独立 512 单元、200 次电容局部 MC | 最坏 DNL=0.1024、INL=0.0656 LSB，均单调 | PDK 抽样权重＋解析静态转移；未包括布线、开关 MC |
| 原生前端、256 个输入码中心 | 所有码中心输出正确 | 未精确测量码边界 |
| 原生前端＋宏比较器/VA 控制，1024 点正弦 | SNDR=48.760 dB，ENOB=7.807 | 约 4.502 MHz、−1 dBFS；有应力告警，不是当前器件级联合性能 |
| TT 固定中点码、五点采样 | 最大保持误差约 0.202 mV | 该固定参考轨迹下通过 |
| SS/0.81 V/−40°C，满幅翻转首次采样 | −27.406 mV，失败 | 下一次采样恢复不能掩盖首次失败 |
| 同一冷角，仅输入改为 150 Ω 理想开关 | −0.001734 mV | 大误差已隔离到原生采样路径 |

来源：`docs/eight_bit_flat_migration.md`、`docs/cdac_flat_8b_device.md`。

## 3. 参考开关与比较器

### 参考选轨

双轨独立测试保留真实 Bootstrap/MOM，使用行为控制和理想比较器，TT/0.9 V/27°C。

原六管栅驱动在 −0.5 LSB 输入时出现约 **1.400 V** 恢复尖峰。改理想栅压后该尖峰消失，但 1× pass 管在 SAR 换轨中仍有 **1.040 V** 端电压超限。

扩大 P/N 并联倍率的五输入对照：

| P/N 倍率 | 同时通过码、误差和应力的输入点 | 最坏参考端电压 | 最大比较前误差 |
| --- | ---: | ---: | ---: |
| 2× | 3/5 | 1.0261 V | 0.4399 mV |
| 3× | 5/5 | 0.9828 V | 0.5216 mV |
| 4× | 5/5 | 0.9600 V | 0.6019 mV |

扩大尺寸也增加参考扰动和栅驱负载。用户选择 **3×＋理想栅压** 合龙；独立测试的通过结论随后被真实异步换轨重新检验。

### StrongARM 初始尺寸

| 项目 | 结果 | 判断 |
| --- | --- | --- |
| TT，输入 ±0.25 LSB，5 fF/输出 | 判决约 191 ps | 满足独立夹具 1.5 ns 目标 |
| 27 个 PVT 点，20 fF、双极性 | 46/54 次满足时限 | 低压/冷角有失败 |
| 物理 transient-noise | 10/30 GHz 噪声带宽估计约 0.652/0.745 mV RMS | 低于分配，但尚未证明带宽收敛 |
| 128 次 MOS 失配 | 门限 σ≈12.73 mV，约 1.81 LSB | 当前明显短板，未制定量产良率门限 |
| 固定中点 CDAC，比较器开/关对照 | 判决时差分 kickback≈0.039 mV，全时段峰值≈0.120 mV | 标称小输入专项，未覆盖全部逐位码型 |

比较器按“先合龙”的安排保留初始尺寸，上述问题没有自动消失。

来源：`docs/cdac8_no_driver.md`、`docs/cdac8_uniform_scale.md`、`docs/strongarm8_baseline.md`。

## 4. 原生异步控制

精简控制器有 21 种 CMOS cell，比较器时钟、写入、更新由本地回路产生。

13 个有界测试均完成，功能/时序检查通过；正常帧各有 8 次比较、写入和更新，FF/0.99 V 仍有应力告警。这批测试主要使用理想模拟端口模型，不能算完整模拟链验收。

最终码保存在工作寄存器，到下一次采样被初始化。没有 EOC 或额外输出银行；比较器卡住时可能读到部分码。

来源：`docs/sar8_simple_async.md`。

## 5. 合龙版本对比

以下均保留真实采样、MOM、参考 pass MOS、StrongARM 和原生异步逻辑；最终参考栅控仍理想化。测试条件为 TT/0.9 V/27°C，但各版输入覆盖不同。

| 版本 | 主要结果 | 留下的问题 |
| --- | --- | --- |
| R1，11 次运行/22 帧 | 码正确；最大比较前误差 0.8064 mV | 参考/比较器端电压达 1.2668/1.2500 V |
| R2，整字对齐提交 | 两个输入下转换尖峰降至约 0.951 V | 下一采样中点恢复仍使比较器达到 1.136 V |
| R3，恢复等待 100 ps、栅边沿 50 ps | 四组两帧：最大保持误差 0.2005 mV；参考/比较器端电压 0.9446/0.9507 V | 短测通过，长历史暴露参考恢复漏事件 |
| B 事件修复，原 12 帧历史 | 第 9 帧从 1 码恢复为 65；误差 −442.8505 → ＋0.1014 mV | 修复的是漏事件；还需验证连续动态输入 |

R3 四组数据属于 **B 修复前**；B 的 12 帧数据属于其独立修复验证。B 后续已同步进 R3 原理图，当前连续正弦由该新导出运行，不能把不同测试混成一组。

来源：`docs/sar8_join_r1.md`、`docs/sar8_join_r2.md`、`docs/sar8_join_r3.md`、`docs/r3_refgate_events.md`、`docs/r3_b_oa_adoption.md`。

## 6. 当前 R3＋B 连续正弦

条件：TT/0.9 V/27°C，500 kHz 差分正弦、峰值 ±0.8 V，10 MS/s；4 帧启动＋20 帧观察，无瞬态噪声或失配。主管仍为 1 µm。

| 检查项 | 已测结果 |
| --- | --- |
| 转换流程 | 24/24 帧均完成 8 次比较、写入、更新，最终码稳定 |
| 观察点码差 | 相对理想码为 −1、0、＋1，无此前大幅跳码 |
| 原始采样保持误差 | 最大 4.464649 mV；14/20 点超过 1.7578125 mV，未通过 |
| 最差帧关断前 1 ns | TOP 差分已比源输入低 4.717954 mV |
| 同一波形的离线拟合 | 等效滞后 1.781 ns，增益偏差 −0.0258% |
| 去直流/基波后的保持残差 | 峰值 8.26 µV，RMS 5.60 µV |
| 关断相关总增量 | 峰值约 0.328 mV，不等于纯通道电荷注入 |

主要误差在跟踪期间已经形成。拟合帮助区分相位、增益和非基波成分，**没有改变采样基准或让原始预算通过**。单周期时域测试不产生整机 DNL、INL、SNDR 或 ENOB。

当前比较器输入对已检查端电压峰值约 0.898 V，无 CMI/LTE 放宽信息；不是全器件、全条件的应力验收。

主管 2×/3×为下一组网表候选，本页不收录尚未完成审核的结果，也不据此改变已采用尺寸。
