The conversion loop.

Circuit blocks

Design sources ↗

Bootstrap sampler

Four parallel thick-oxide main devices per side acquire the input. The routed r2 revision improves gate discharge at SS cold. FF-hot held-voltage error remains open.

Sampler extraction ↗

Binary MOM CDAC

Each side uses eight weighted capacitors and one unit dummy. The stacked, paired layout manages TOP parasitics and fill loading. Standalone TT gain error is 4.22%.

CDAC bit weights ↗

StrongARM comparator

An 11-MOS latch drives the SAR handshake. The extracted v8 block has a 12.05 mV offset standard deviation over 200 mismatch draws.

Comparator measurements ↗

Single-edge SAR

Native cells implement one write edge, a precomputed trial word and a DEL250 chain with registered per-bit taps. The taps allocate settling time before each subsequent comparison.

Controller adoption ↗

Reference driver

Native logic decodes CODE and PRESET into true and complementary drives. Bit-scaled switches connect both CDAC sides to the fixed reference rails.
