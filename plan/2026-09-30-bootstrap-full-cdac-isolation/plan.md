# Full-CDAC bootstrap isolation sequence screen

## Goal and starting state

Test whether the independent `OFF_MAIN`-before-BOOT-reset sequence, when
combined with true bottom-plate CDAC sampling, reduces raw held error.
Compare bottom- and top-plate paths using the **same** protected T28/ideal-relay
bootstrap subcircuit in the same full-CDAC fixture. Also check the previously
failing physical T28 top-clamp variant at the input endpoints. This is a
netlist-only architectural screen, not an OA implementation.

At start `exp/bootstrap-protected-eval` is clean. The exact read-only OA
exports are SHA-256 `965cbc2f99712c0f5d72af0eefcf28abdf398340f31cff32d96a0e1fd36e50ac`
(ideal-clamp full CDAC), `02c8ffc923915c279c1a316a1984e8cb677e6c3be06147a822f9d42aa36944ef`
(T28-clamp full CDAC), and `f466793e8655f2d81bdb7ce98d1041f00cdd90a374be3341750d2cb22a9bdd4d`
(protected bootstrap). The protected subcircuit is generated by the previous
verified `reset_gap_1ns` transform. EVAS cannot solve PDK MOS KCL/KVL;
run Spectre 21.1 via `t28_io`.

## Steps and validation

1. Assert all three source hashes and original topology counts. In a copied
   full-CDAC deck only, replace the shared `sar_bootstrap` definition with
   the protected T28/MN9-body-VSS/split-GMAIN subcircuit, add `OFF_MAIN` to
   the CDAC formal and all 24 bootstrap calls (22 bottom and two top-plate
   sampling switches), and add its independent clock.
   Keep all capacitor values, clamp and reference switches, PDK includes,
   source resistances, and differential input stimuli otherwise unchanged.
2. Keep clamp release 0.5 ns before PHI falls; switch main gate off at
   250.2-250.3 ns, reset PHIB at 251.3 ns, and connect base references at
   252 ns. Run five differential inputs (-0.8,-0.4,0,+0.4,+0.8 V) with the
   ideal top clamp. Run at least the two endpoints with the T28 top clamp.
3. Save top/bottom differential nodes and representative bottom plate/GMAIN
   nodes. Measure acquisition, clamp-release, switch-off, pre/post reset,
   reference handoff, and 270-ns raw held error against the charge-conservation
   polarity oracle. Compare top and bottom **within each new deck**; label
   historical results as different-switch context only.
4. Require exact bounded deck transformations; Spectre `result.ok`, finite
   aligned waveforms, no floating-node/syntax errors, phase-order assertions,
   per-case JSON, and a warning inventory. A raw-error pass requires all
   five ideal-clamp bottom cases below 0.439 mV, and cannot by itself
   authorize physical promotion. Do not mask SOA warnings.
   If endpoint nonlinearity appears after the reference handoff, run one
   additional +0.8-V ideal-clamp deck with selected MN11 and source-resistor
   currents to test possible reverse conduction when `GMAIN=VIN` but the
   bottom plate moves toward VCM. This probe changes saves only.
   If that path is confirmed, run a bounded ideal off-bias ablation:
   connect only `SHOLD`'s held terminal to VSS instead of VIN in the copied
   protected subcircuit, initially at +0.8 V with the same current probe.
   Expand to the remaining ideal-clamp inputs only if the endpoint screen
   materially improves. This is a mechanism bound, not a physical T28
   gate-driver proposal or an OA change.
   With that mechanism bound established, also run the +0.8-V T28-clamp
   endpoint under the same ideal VSS-off bias to separate residual physical
   clamp error from main-switch re-conduction; do not infer an all-input
   physical-clamp pass from one endpoint.
5. Python compile, JSON parse, `git diff --check`, owned-diff review, factual
   log, and local commit. Commit as `test: screen protected bootstrap in full CDAC`;
   do not push without user request.

## Outcome

Fifteen copied-deck Spectre transients completed: seven VIN-relative cases,
five VSS-off ideal-clamp cases, one VSS-off physical-clamp endpoint, and
two current-only probes. With ideal clamp, VIN-relative off bias fails at
±0.8 V by 6.261925 mV, whereas ideal VSS-off bias passes the five-point
bottom-plate raw-error screen with a 0.004218-mV maximum. The probe proves
that after BASE handoff, source-relative GMAIN causes high-side MN11
reverse conduction: one B9 MN11 carries 6.25772 uA and the 50-ohm source
path carries 68.83530 uA. VSS-off removes that sustained current.

This is not a physical pass. The ideal VSS-off endpoints print MP8 CMI
warnings, the matched top-plate control fails, and the T28-clamp +0.8-V
VSS-off case remains at -7.538001 mV with clamp SOA warnings. Exact
evidence and scope limits are in `docs/bootstrap_full_cdac_isolation.md`.
