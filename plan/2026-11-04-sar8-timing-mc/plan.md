# B 版模块失配与闭环时序方案

本次交付为方案。以冻结 B 网表为基准，复用既有五点结果选择关键工况，取消独立的五点 PVT 重测与逐位复查阶段。已有数据见 verification/sar8_campaign/ab_pvt 和 verification/sar8_mc/blocks。

| 阶段 | 样本与测试台 | 交付 |
|---|---|---|
| ② TT 模块失配 | 比较器、CDAC 各累计 200。保留 v2 原条件，各复用 4101–4130，拟各补 4131–4300 共 170 个。比较器开启完整器件失配，CDAC 保留 18 个独立 MOM 实例。 | 每种子有效门槛、相对其门槛的小差分判决时间、位权和静态 DNL/INL，以及有效数、告警、超时。失调分布用于初定微调范围，位权分布用于判断 CDAC 是否值得校准。 |
| ③ 关键角闭环短测 | SS 冷、FF 冷各 50 个局部失配样本。B 原生异步 SAR、接收负载、外部时钟和参考边界保留；数字实例保留所在角的模型，随机变化限定于比较器和 CDAC。先确认该角统计 section 可用并验证实例抽样。 | 低中高码、127/128 附近小差分及首帧/正常帧，逐位输出建立误差、有效判决至锁存间隔、复位次序、八位事件计数和帧期限。失败定位到运行、帧、位及事件。 |
| ④ 定位与校准复核 | 控制路径余量不足、漏脉冲或过早锁存时，针对该路径加 30–50 个样本。真实微调候选具备后，另取 50 个未参与选型的样本验证校准闭环。 | 对照校准前后残差、码是否顶格、最小判决余量、额外负载及超时。控制路径与校准支路分别归因。 |

③ 的 SS 冷选择依据为已有关键码中 B 整帧最长 39.797 ns；FF 冷为已测最小逐位安静裕量 388.52 ps。二者均为针对性筛查依据。CDAC 建立误差取比较启动时与同开关字、同样本充分建立值的差，记录输入等效 LSB；0.25 LSB 仅作诊断预算。比较超时以真实接收端、锁存边沿和本帧时限判定，边界相邻码另列。各角分别统计，保留无效样本与失败，不能用结果外推量产良率。

本次仅写本方案、追加 plan/log.md。初始 git status 含分支行共 1433 行，既有改动保留。远端 OA 所有权为 none。冻结网表、PDK、历史结果均只读。执行时由主聊天走 managed 流程，限仿真 4 线程/1 GiB、分析 256 MiB、回收 32 MiB；脚本、结果和远端运行路径在首次提交前登记。方案以范围、样本算术和来源核对为验收；不提交 Git 或推送。
