CDAC 采用 `2 × 最大底板对目标参考轨残差 / LSB`，不依赖名义二进制权重。在正电容归一化假设下，最坏 0.013241 LSB 距 0.25 LSB 筛查线还有 **0.236759 LSB 幅值裕量**。最短可用建立区间为 1.977390 ns，它是更新/关闭到比较的间隔，不是实测建立完成后的剩余时间。首帧首位的名义权重建立时间字段在无先前越界点时默认为零（共 36 项），不能解释为物理零裕量；本次通过结论使用残差界，不使用该默认值。

偏移统计选名义码 12、63、64、127、128，避免端点饱和。表内是实际码减名义码；同一种子五点的偏移跨度最大 1 码，表现以整体平移为主，但这些粗量化点不能独立区分比较器失调、CDAC 权重误差及其他误差，也不是精确 Vos 或 DNL/INL。种子五点偏移中位数分布及逐帧码字均保存在 JSON/CSV。
