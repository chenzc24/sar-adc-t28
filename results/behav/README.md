# B 版行为视图验证

- [python_crosscheck.json](python_crosscheck.json)：Python 二进制决策对独立闭式量化；实测中心码、TT 时序近似和高频差异。
- [model_audit.json](model_audit.json)：旧模型来源、处理和当前源码身份。
- [native_crosscheck.json](native_crosscheck.json)：原生 Spectre 与 Python 的确定性事件、码字及独立输出引脚对照。
- [native_provenance.json](native_provenance.json)、[native_status.json](native_status.json)：实际运行身份、冻结规格、回收校验和资源记录；[原始告警](native_warnings.txt)。

Python 的 2050 个确定性输入对独立闭式量化一致；34 项本地检查通过。256 个中心码与 B 版实测边界对应一致，十帧 TT 码字一致，近似转换时间最大差约 0.13 ns。这是协议层 TT 近似，不是精确晶体管时序回放。

原生运行 `sar8-behav-cross-v1` 的仿真与受管分析均完成、退出码均为 0。每种情形 2050 帧，共 16400 条事件记录和 16400 次独立 D0–D7 电压探测，比较失败数为 0；最大事件时间差 2.693e-17 s，验收容差为 2 ps。

| 情形 | 帧数 | 观察结果 |
| --- | ---: | --- |
| 名义、采样增益/偏移、比较器偏移、MSB 位权、有限建立、输入相关延时 | 每项 2050 | 全部完成，与 Python 一致 |
| 故意增加比较延时 | 2050 | 全部正确识别为帧内超时，保留部分码字与具体位 |
| 故意令 bit3 不响应 | 2050 | 全部正确识别为比较器停滞，未误报成功转换 |

仿真耗时约 67.7 s、峰值 RSS 170.6 MiB；分析约 1.2 s、峰值 RSS 34.6 MiB，均在配方预算内。`VACOMP-2435` 提示旧环境变量 `CDS_AHDLCMI_ENABLE` 不再受支持，Spectre 使用默认编译流程；原文保留，未隐藏或改写为零告警。

1024 个高频源电压采样的理想量化与真实 B 码字有 908 个不同，最大 3 LSB。源采样、实际保持、有限采样传递和输出拟合相位有不同定义，保留该差异；不能据此宣布真实 B 有 908 个错码，也不能宣布理想模型已经复现 B 的高频模拟性能。

随机模型、PVT/原生失配、物理启动预充、端压、功耗、噪声良率和版图寄生保留各自验证范围。

旧模型共 33 份已建立哈希与去向索引。旧 10-bit 和专用实验模型留在历史区，当前模型没有历史目录的运行时依赖。
