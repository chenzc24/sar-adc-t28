# MSB 末级 D2 驱动候选

`reference=minimal_msb_d2` 仅把 MSB 两侧末级原生标准反相器 D1 改为 D2，保留门级数、逻辑、比较器及外部时序。当前设计仍为 `c024fd5` 的 `minimal_direct`，候选未采用。

展平 MOS 实例数为 1075 → 1079；增加来自两个 D2 标准单元内的并联器件，不是新增逻辑门或保护级。

## 已完成的端压结果

同一 18 帧整机激励、同一模型和求解设置、2 ps 最大步长，按 [SOA 工程规则](../../specs/soa_rule.yaml)统计所有物理 MOS 端点。

| 工况 | MNINP 最大绝对 Vgd，原版 → D2 | 最差 10 ns 内累计 >1.1 V 时间，原版 → D2 | 比较器 33 项端压 | 整机剩余违例 |
| --- | ---: | ---: | --- | --- |
| TT | 1.115417 → 1.025552 V | 77.916 → 0 ps | 数值通过 | 0 |
| FF 冷 | 1.205524 → 1.194894 V | 166.050 → 47.654 ps | 数值通过 | 8 项 SAR 存储单元 MM64 Vds |
| FF 热 | 1.191259 → 1.132627 V | 173.498 → 34.655 ps | 数值通过 | 0 |
| SS 冷 | 1.061091 → 0.905049 V | 0 → 0 ps | 数值通过 | 0 |
| SS 热 | 1.009114 → 0.900985 V | 0 → 0 ps | 数值通过 | 0 |

五个工况的观察器码字均为 18/18 正确，共 90 帧。该单变量结果支持此前[输入顶板切换下冲的定位](comparator_input_undershoot_20261115.md)：无需改变比较器管级电路，改善 MSB 负载驱动已使比较器在这五个确定性短测工况下满足规则。FF 冷仍有 8 个 SAR 存储单元的独立违例，最差约 1.183443 V、131.527 ps，不能称整机端压全部合格。

五个工况的同源独立时序分析也已完成：每帧 8 次比较、写入、更新，采样关闭、输出稳定、接收有效性和底板建立筛查均通过。

| 工况 | 最长转换时间 | 最小底板稳定余量（除首帧首位） | 比较结果到写入的最小余量 | 最大采样关闭误差 |
| --- | ---: | ---: | ---: | ---: |
| TT | 28.899 ns | 2.211 ns | 214.628 ps | 0.00591 LSB |
| SS 冷 | 39.502 ns | 2.835 ns | 296.451 ps | 0.03826 LSB |
| SS 热 | 33.984 ns | 2.452 ns | 276.864 ps | 0.00324 LSB |
| FF 冷 | 25.693 ns | 2.084 ns | 177.339 ps | 0.01005 LSB |
| FF 热 | 27.536 ns | 2.154 ns | 193.828 ps | 0.00743 LSB |

SS 两角首帧首位的原始连续稳定余量为 0：原分析器在缺少此前非零 last_bad 时间戳时，用比较时刻代入，产生保守的零值。因此上表统一排除该首个比较事件，不能据此宣称已量化启动首位的连续稳定余量，也不能把原始零值判为真实零裕量。包括启动首位在内，所有比较沿的瞬时底板误差判据均通过；原始字段、首位测量和限制保留在 JSON 中。

底板建立筛查是相对实际参考轨的标称位权误差界，不等于独立测得浮动顶板的全部 kickback 误差。模型原始警告保留，即使本项目的新端压规则数值通过，也不抹去原模型阈值告警。

更强驱动的瞬态负载代价需要保留。上表比较既有 10 ps 短测与本次 2 ps 波形，是诊断峰值，不是同分辨率精密延迟/功耗标定；电流不是 ADC 平均电源电流，开关端口电流还含位移电流。五角的比较前底板建立筛查均通过，尚未做本候选功耗、FFT、MC 或 PEX 验证。

五点端压分析均已完成，比较器全部通过本次数值筛查；只有 FF 冷仍有上述 SAR 存储单元违例。SS 原版参考为既有 10 ps 捕获，本候选五点均为 2 ps 捕获。五点同源独立时序分析也全部完成。候选继续独立保存，当前默认设计未切换；历史 FFT、MC 和全码指标不转移为本候选指标。
