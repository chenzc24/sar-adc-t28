# T28 单位 MOM 与共顶板 1∶2 阵列试验

本方案保留已完成的单位与三颗 MOM 实验边界；当前完整 CDAC 工作见 [Layout 入口](../README.md)，不受本试验的历史范围限制。

## Problem Statement

SAR8 B 版的 CDAC 已有晶体管级网表和前仿结果。开始画整侧 CDAC 之前，需要确认一套能在现有 T28 Virtuoso 环境中重复生成版图、用独立参考跑物理验证并把寄生带回 Spectre 的流程。小试验应能原处修改并回滚，方便验证走线改动的实际影响。

## Solution

在个人试验库中生成一个单位 MOM 和一个三单位共顶板阵列。用冻结 B 的单位电容规格建立独立文本参考。对同一份导出的 GDS 执行 Calibre DRC、LVS 和保留耦合的 PEX，再用固定的 TT Fixture 对比前仿和后仿。通过一次单变量走线修改和回滚验证迭代流程。所有结论绑定实际输入和工具产物。

## User Stories

1. 作为版图设计者，我希望直接调用 T28 原生单位 MOM，以便后续 CDAC 采用同一器件实现。
2. 作为版图设计者，我希望从 OA 回读器件参数、引脚和实例数，以便发现默认值或端口映射错误。
3. 作为 CDAC 设计者，我希望用三个等值单元组成 1∶2 阵列，以便验证重复放置和并联映射。
4. 作为 CDAC 设计者，我希望固定 `TOP`、`B0` 和 `B1` 的拓扑，以便从电气上比较不同走线。
5. 作为验证人员，我希望 DRC、LVS 和 PEX 引用同一份 GDS，以便排除验证结果来自另一版版图。
6. 作为验证人员，我希望从独立文本参考执行 LVS，以便 OA 中意外的连线改动不会同步改变判定依据。
7. 作为验证人员，我希望临时断开一根连接时 LVS 拒绝该版图，以便确认检查能发现真实错误。
8. 作为验证人员，我希望区分 MOM 本体与布线产生的寄生，以便解释有效位权的变化。
9. 作为仿真使用者，我希望用相同 TT Fixture 读前仿和 PEX DUT 的端口响应，以便比较电容、有效权重和建立。
10. 作为仿真使用者，我希望直接检查提取网表中的关键网间耦合，以便识别误用对地等效的情况。
11. 作为版图设计者，我希望每轮只改一个走线变量，以便把测量差异归因到具体的几何修改。
12. 作为版图设计者，我希望每个试验对象只有一个工作 cell，以便原处修改并恢复上一次通过的布局。
13. 作为审阅者，我希望能从 GDS 散列、报告和 Run 回执定位证据，以便核对每一轮实际验证了什么。
14. 作为项目维护者，我希望保留一个当前生成入口和简短结果记录，以便后续在同一流程上扩到完整 CDAC。

## Implementation Decisions

- 单位件取冻结 B 的 `cfmom_2t` 单位几何。小阵列固定为三颗等值单位，`TOP` 接三颗顶板，`B0` 接一颗底板，`B1` 接两颗底板。文本 LVS 参考独立写明拓扑与单位几何，并核对设备识别和参数归并。
- 使用 T28 原生 PCell、合法引脚层和实际几何。生成后的实例、端口和参数必须从 OA 回读。
- 两个试验对象分别使用一个固定 cell 名。版图生成脚本和布线参数原处修改。使用一个滚动的回滚检查点保留上一次通过的生成输入，通过原生成入口恢复工作 cell。失败与对照轮次保留散列和工具报告，Run ID 只标识证据。
- DRC、LVS 和 PEX 使用获准的 T28 deck 和映射。验收读取工具输出，检查实际端口、连通、结果标记和网间寄生。PEX 使用 Spectre 可绑定的文本视图，保留需要比较的网间耦合。
- 前仿和后仿通过同一 Fixture 测有效支路电容、比例和阶跃响应。仿真使用项目既有 managed 流程，绑定 GDS、参考及提取网表身份。若版图候选的电气差异没有超过可分辨范围，报告实测差异和测量范围。
- 布线对照选定 B1 的一段引出走线，在原工作 cell 内改变一个几何量。对照结束后恢复确认过的基准，再回读并复核。另用同一回滚机制临时制造断线作为 LVS 反例。

## Testing Decisions

- 验收入口是从 Virtuoso 导出到 Calibre 与 Spectre 的整条链路。以 OA 回读、GDS 端口与散列、工具报告、提取网表和波形为依据。项目既有 managed Run、冻结输入和独立分析回执是仿真侧的先例。
- 单位件须有正确的 PCell 参数和两个端口，并完成适用的单元 DRC 与文本参考 LVS。阵列须有三个器件和三个端口，LVS 保持 1∶2 拓扑。临时断线须由 LVS 明确拒绝，恢复后须重新匹配。
- 记录采用的 DRC 检查范围及实际结果。试验若遇到 deck、许可或小单元规则限制，按实际报告记录未通过或未运行的项目。
- 阵列 PEX 须确认 `TOP` 到两位底板的提取网络和实际网间耦合，记录提取模式和可解析的寄生。前后仿须使用相同测量条件并到达预期终点。将精确的有效权重与阶跃结果作为测量值记录。
- 单变量对照须保留同一拓扑和仿真条件，比较走线变化与寄生及波形变化。回滚须恢复基准几何、端口和连接。实际验证覆盖小单元和三单位阵列。

## Out of Scope

- 整侧 CDAC 版图、量产匹配、完整 ADC 性能和流片签核。
- 扩展已有 OA 电路库或更改冻结 B 的电路、仿真基线和规格。
- Num-Layout、开源工艺迁移及通用版图生成平台。
