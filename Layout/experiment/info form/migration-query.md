# LayoutML 只读查询迁移试验

2026-11-18，TSMC28 SAR ADC。建议先迁比较器的器件与差分布线查询，以及 CDAC 审阅版的 MOM 摆放和位分组查询。Bootstrap 的 GRESET 和体端关系继续从 CDL、OA 和提取结果核对。此次测试使用冻结输入及临时副本，另对服务器已保存的 OA 做了一次只读抽查和导出。逐次耗时、输入与输出哈希、失败记录均在[测量数据](migration-query.json)。

## 生成映射与查询的成本

| 输入 | GDS | 本地 GDS＋CDL → flat LML、meso LML、store | 重复性 |
|---|---:|---:|---|
| 比较器 V3、V4、V6、V7 | 28–32 KiB | 各跑 3 次，全部在 0.193–0.209 s 内 | 每个版本的三份输出逐字节一致 |
| Bootstrap compact | 96 KiB | 1.078–1.145 s，3 次 | 三份输出逐字节一致 |
| CDAC 审阅版 | 940 KiB | 43.72 s、68.07 s | 两轮输出逐字节一致 |
| CDAC 含填充样本 | 5,172 KiB | 一轮在 100 s 测试预算处终止 | 完整耗时与映射质量待测 |

每轮使用独立进程和输出目录，计时含 Python 启动与文件写出，关闭 Viewer。含填充样本与审阅样本取自两个实际工作文件，规模差异不能单独归因于填充。

比较器每版在同一 Python 进程内重复查询 15 次。每次重新打开映射，取 OUTP、OUTN 的线段矩形和单孔中心，中位数为 0.176–0.209 ms。每次从 GDS 新建 M1–M3 和 VIA1/2 连通图、从端口定位两张网并取同口径几何，中位数为 3.079–3.719 ms。GDS 结果若已缓存，这个倍数不适用。CDAC 打开已生成的 flat LML，只数 TOPP、TOPN 显式布线对象，中位数为 5.06 ms（21 次）。

服务器端从已保存的比较器 OA 导出 GDS 用 2.09 s，另起 SCP 下载用 1.80 s，本地映射用 0.24 s。三个步骤合计约 4.13 s，另有远端任务发起开销。新导出与冻结 V7 逐层多边形 XOR 为空。独立启动后台 Virtuoso，读取该 cell 的实例、过孔、端口和按网标记的图形数，共 11.32 s，含启动和关闭。常驻 bridge 连接被拒，在线会话查询及未保存修改的延迟待测。

## 映射能回答哪些问题

| 查询 | 对照方法与实测结果 |
|---|---|
| 比较器器件与摆放 | 四版各 11 个逻辑 MOS 的名称、型号、栅、体、无序源漏对、总宽及沟道长与 CDL 相符。GDS 的 OD 与 PO 相交，得到指总数 14、14、12、14，与各版映射相符。总数不单独证明每根指的身份。 |
| 比较器 OUTP、OUTN 的走线 | 从源 GDS 的输出标签独立提取两张金属网，逐一对比 68 段顶层布线矩形及 64 个过孔中心，四版均相符。走线统计扣除完全被主干覆盖的图形，过孔统计限 M1–M3。 |
| 小改动能否反映到查询 | 在私有 V4 副本中将一根 OUTP 的 M2 支线右端缩短 10 nm。重新生成映射后，两张输出网的差异中仅出现这一处，过孔坐标相同；改后源 GDS 独立查询吻合。 |
| CDAC 阵列与开关 | 680/680 个 MOM 中心与源 GDS 实例逐个相符，无序端网对的计数与 CDL 相符。19 种逻辑端网组合对应 19 种物理导体组合。涉及 GDS 顶层标签的 682 个 store 端口中心均落在对应导体上。32/32 组开关管的型号、栅、体、无序源漏对、长度及总宽与 CDL 一致。内部 BN/BP 的绝对命名及电容正负极性仍需独立依据。 |
| CDAC 整网过孔 | TOPP、TOPN 的 flat route 各有 134 条 path、0 条显式 viastack。源 GDS 全层级提取显示两张网**各有 1,280 个 VIA1 和 1,024 个 VIA2**。按实例摆放展开 MOM store 后，这些 cut 的物理面积全部被覆盖。查询整网还需判定每个 cut 的导体归属，不能将所有 MOM 的 cut 简单相加。 |
| Bootstrap 电容、MOS | 200/200 个 MOM 中心吻合，200 个 BBOT/BTOP 无序端网对与 CDL 计数一致，两端在 GDS 对应两个不同导体。两个都是内部网，不能据此独立命名极性。13 个 CDL MOS 按电气关系合为 12 组，仅 8 组与映射完全一致。涉及 GRESET 的两组未保留正确关系，两组 PMOS 的 CDL 体端为 BTOP、映射给出 VDD。该结果定位到查询映射与参考电路的差异，未对物理短路作判定。 |

## 输入有问题时会怎样

V4 的同一份 GDS 做了两次负对照。只把参考 CDL 中 NINP 的栅由 VINP 改为 VINN，工具仍正常退出，7 个端口、10 张命名网络仍在，原来的两根 NINP 指却都变成 XDM。物理端网组合甚至仍能与正确 CDL 的组合数对上，只数网络和尺寸会漏掉这个问题。省去 CDL 时也正常退出，7 个外部端口仍齐全，但逻辑器件名称仅余两种。迁移时应绑定 GDS 与参考网表的哈希，并检查正在使用的器件名、关键端子关系。

## 建议的迁移顺序

1. 比较器先迁器件定位、差分线分层长度、外部走线过孔、镜像偏差等查询。每次产生新 GDS 后刷新映射，同版结果复用。
2. CDAC 在审阅版几何变化后按需重建，供同版多次查询。输出中过孔数明确标注“外部 route”或“含 PCell 内部的物理整网”。可先迁 MOM 位置、位分组、外部已赋名端口。
3. Bootstrap 先迁 MOM 摆放；GRESET、浮动体端与完整器件连接沿用 OA/CDL/LVS。含填充 CDAC、SAR 数字单元层级、未保存 OA 修改均未取得足够的迁移证据。签核与寄生量继续引用同版 GDS、DRC/LVS/PEX。

原始样本、转换日志及本机复核脚本位于 [work/layout/layoutml-migration-survey](../../../work/layout/layoutml-migration-survey/)。其中 `measure.py` 测转换，`out_query.py` 做独立金属连通与查询耗时对比，`mom_check.py` 核对电容，`change_check.py` 验证单线修改，`mos_check.py` 核对 MOS 关系。实验使用固定的 LayoutML 提交 `e19fb224207147ddb531d0ea2b1812b5862fd7e4`。
