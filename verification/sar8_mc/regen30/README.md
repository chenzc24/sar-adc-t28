# 再生支路失配分组对照，30 个配对种子

建议优先调整交叉耦合 NMOS 对 MNLATN/MNLATP。在输入对失配已关闭的条件下，
关闭再生 NMOS 的失配对总体门限离散的改善更大，逐颗剔除后排序一致。

保持 B 版 1 µm 输入管和真实 CDAC 保持接口。三组均关闭输入对失配，
并对每颗样本核对其余器件的原生随机参数。统计对象为带符号的保持输入门限。

| 条件 | 门限均值 (mV) | 门限样本标准差 (mV) |
|---|---:|---:|
| 对照 | -0.916 | 5.027 |
| 再关闭再生 NMOS | -0.183 | 1.714 |
| 再关闭再生 PMOS | -0.749 | 4.005 |

关闭 NMOS、PMOS 分别使标准差降低 3.313 mV 和 1.023 mV。
两组残余标准差之差（PMOS 关闭减 NMOS 关闭）为 +2.291 mV，
按种子配对重抽样的 95% 百分位区间为 [+1.144, +3.378] mV。
逐次去掉一颗种子的差值范围为 [+1.733, +2.413] mV。
单个门限搜索分辨率约 0.125 mV。这是 TT 的模块失配诊断。
