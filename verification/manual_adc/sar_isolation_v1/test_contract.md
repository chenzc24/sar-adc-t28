# SAR隔离测试：首轮指标与TB定义

本轮对象是手搭ADC的 `manual_sar`：原生标准单元逻辑＋17个理想delay。源为 `../candidate_io_v1/dut.scs`，保持现有复位极性与raw正侧输出映射。此文定义待实施实验，不是已完成结果；不使用RC版时序作为本轮验收。

## 目标与条件

| 项目 | 首轮定义 |
|---|---|
| PVT | 先TT、0.9V、27°C。后续相同边界下覆盖SS0.81V−40/125°C、FF0.99V−40/125°C；五点是风险筛查，不代替完整PVT |
| 周期/采样 | 100ns；外部CLKS高约40ns；首次上升50%为10.025ns，关闭50%为49.975ns，下一上升110.025ns |
| 输入摆幅/边沿 | 数字0至VDD；外部CLKS线性0–100%边沿50ps；VA比较器transition参数trf=50ps，另报告实际10–90%边沿 |
| 逻辑判定 | 50%VDD测事件；稳定区VOH≥0.9VDD、VOL≤0.1VDD；不能把合法翻转过程当稳定区违规 |
| 功能 | 每帧八次有效比较，按bit7到bit0接收；16帧重复模式无错误、无额外比较、无跨帧串码 |
| 移位链 | CLK7先升，随后CLK6…CLK0各升一次，升后保持到复位；电平序列00→80→C0→…→FF，是热码，不是独热码 |
| 复位 | CLKS采样开始后1ns内八个移位Q全部低；采样稳定期间无比较脉冲。输出寄存器此时仍应正确锁存上帧 |
| 转换预算 | 采样关闭50%起40ns内完成八位并建立最终raw码；在60ns可用间隔内留约20ns余量。此40ns为新分配目标，不是已有测量 |
| 输出 | 下一采样上升沿锁存上帧码；1ns内达到正确稳定输出。首个有效输出在完成首帧后的采样沿；t=0输出初态不作为有效数据 |
| setup/hold等 | 逐个DFF记录D/CP、CDN/CP相对时间；按对应库角实际setup/hold、recovery/removal、最小脉宽检查。暂无可信库约束时标unknown，不捏造统一数值 |
| 端压 | 每只被测MOS六组同时刻端差与其PDK限制比较；当前核心模型活跃阈值0.99V。保留峰值、持续时间、阶段及CMI原日志，任何超限都不宣布电气通过 |
| 数字供电预算 | 初定VDD供电稳态平均≤100µW，约10pJ/转换，为1mW整机目标预留预算；这是拟定目标。理想delay/行为源供能、输出负载条件分列，不当作完整物理实现功耗 |
| 输出负载假设 | DO每路先用5fF声明的测试负载，非版图提取值；报告注明。内部真实扇出保持 |

时序预算和功耗预算用于研究；测量失败要说明原因，而不是自动改拓扑或放宽ADC规格。

## TB-A：先做已知判决序列隔离

真实：SAR标准单元、复位反相器、VALID组合逻辑、比较时钟buffer和原生内部扇出。17个延时位置保留理想传输delay（tloop=2ns、tgate=100ps）。

理想：电源、采样时钟、比较器响应器、参考电压。响应器只监听DUT输出CMPCK，每次上升按目标码下一位在200ps后发布DCMPP/DCMPN，输出转换参数50ps、Thevenin输出电阻1Ω；CMPCK下降后复位到00，取消未发布响应。VALID由真实OR2生成，不另给独立VALID时钟。200ps是VA内部计划延迟，输出跨50%还包含transition/负载时间。

已知帧序列为0、255、85、170、128、127、1、254，重复两轮：覆盖全0/全1、交替、MSB边界、LSB变化及跨帧翻转。每帧按MSB到LSB返回；目标位1时P=VDD/N=0，位0时P=0/N=VDD；复位两路都0。信号由CMPCK触发，不按绝对时间硬塞一串判决脉冲。

TB-A不接模拟输入，也不需要CDAC输出影响判决；这是逻辑/端压归因。参考控制输出必须另挂声明负载：采用当前参考MOS的静态栅负载副本，端点接对应参考轨，不引入CDAC真实切换；沿用原W/L/nf/multi。它包含工作点栅电容，不包含动态底板Miller反馈。bit0没有真实电容支路，不虚构参考栅负载。

实际负载值/输入slew必须在TB完成后测量；本定义没有把未知栅电容编成任意fF数值。若理想delay不收敛，作为独立数值问题保留，不自动换RC。

## TB-B：随后接理想模拟闭环

用已写的manual8_sample、manual8_cdac、manual8_cmp，SAR仍是真实标准单元。首位P/N只交叉一次；按当前参考开关极性控制。真实参考MOS栅负载副本仍挂在SAR端，不能因VA控制端没有输入电容而省掉。

| 理想模块 | 初始设置 |
|---|---|
| 采样 | Ron1Ω/Roff1TΩ、trf10ps；qclk=0、cin=0 |
| CDAC | Cunit10fF、每侧128C=1.28pF、ctop=0；参考Ron_unit10Ω且随权重反比缩放；无失配/注入 |
| 比较器 | td200ps、trf50ps、rout1Ω；vos/treg/cin/qkick均0；无噪声。输出负载由真实接收FF提供 |
| 参考与输入 | VREFP=.9V、VREFN=0，共模.45V；静态码中心输入，不在保持期间改变 |

输入差模按Vin_diff=(code+0.5)×(1.8/256)−0.9，正负输入分别为.45±Vin_diff/2。这只为避开码边界歧义，不能当精度/线性度测试。判决依赖真实SAR控制后的CDAC顶板，因此可核对映射、极性和握手。

TB-A通过与否不妨碍保存端压失败；TB-B仅在边界/握手行为明确后开展。首轮不叠加噪声、失配、随机抖动和真实模拟反冲，后续每次仅改变一个明确参数。

## DFF监控

全部32个DFF监控外部D/CP/Q，移位DFF另监控CDN。逐管端压覆盖需要记录实际被保存的内部节点清单，不能只依赖打印有限次的CMI。

| 类别 | 实例与连接 | 重点代表 |
|---|---|---|
| 移位8个 | I5→I6→…→I12，输出依次CLK7→CLK6→…→CLK0；CP=VALID，CDN=CLKSN，I5.D=VDD | I5：固定D自然对照；I12：后级清零/下冲；其余六级查传播一致性 |
| 正侧判决8个 | bit7到0为I14、I16、I18、I20、I22、I24、I26、I28；D=DCMPP，CP=相应CLK位 | I14/MSB、I22/bit3、I28/LSB |
| 负侧判决8个 | bit7到0为I30、I32、I34、I36、I38、I40、I42、I44；D=DCMPN | I30、I38、I44，与正侧对照 |
| 最终输出8个 | I46_7… I46_0；D接正侧raw位，CP=CLKS | I46_3：已观察MM79事件；I46_7：MSB；其他位全部核对输出 |

移位重点内部节点：qf/qf_x、mq/mq_x、net176/net184、内部时钟clkb/clkbb；相关MM76/MM3/MM4/MSLTn1及MM64–MM66。判决/输出FF重点mq/mq_x、net0118、clkb及MM79/MM60，MM1按原生日志追加。连接以对应标准单元原生子电路为准，不能把两类FF的内部命名混用。

首组波形按三组展示：①CLKS/CDN/VALID/CLK7…0及热码；②CMPCK/DCMPP/DCMPN/代表接收DFF的D、CP、Q；③复位与数据变化窗口的内部节点、同时刻端压及局部电流。功耗图与失败窗口分开，不用全程缩图掩盖ps尖峰。
