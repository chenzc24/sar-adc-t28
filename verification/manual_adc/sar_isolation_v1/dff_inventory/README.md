## 清点范围和方法

扫描服务器 `/home/process/tsmc28n/STD_CELL` 下已展开的非 LPE 晶体管 SPICE。11 个路径去除内容完全相同的副本后为 **9 套库**：12T30 RVT/HVT/LVT、12T35 RVT、12T40 RVT/HVT、BWP40 RVT/HVT，以及 TSMCHOME 下额外的 7T30 RVT。存在文件不等于已经绑定到当前 OA 或已确认模型配套。

主库 `tcbn28hpcplusbwp12t30p140` 共 1186 个 subckt，其中 **336 个具有 CP/CPN 与 D/DA 输入的 DFF 型号**，包括扫描、使能、MUX、特殊优化及不同驱动档。该数字不是336种可直接替换的内部架构。

比较先合并 D/G/S/B 完全相同的并联 MOS，保留 N/P 类型及各端角色、固定外部端口名称，允许内部节点改名。图指纹分组后，逐个用精确节点映射确认同组等价；W/L/Vt 单独比较。主库得到 123 个严格端口标记图组；增加扫描端口、复制独立内部串联支路也可能增加组数，因此仍需人工检查关键锁存支路。源路径、SHA、全部型号及比较结果见 [inventory.json](inventory.json)。专有原文只在忽略的 `output/manual_adc_dff_inventory/` 中，不放进提交内容。

功能资料：原厂170a版 TT0.9V/25°C手册，PDF页208、232、249、269、324、327、708–709、852–853。项目测试温度仍为27°C，手册数值只作选型参考，不作为实际延迟/功耗预测。已查看异步清零、扫描候选的符号/真值表页面。CCS180a与SPICE170a的正式配套关系仍未确认。

## 不能把驱动档位混为一谈

| DFQD1 → DFQD2 | 合并并联管后拓扑相同，只有连接 Q 的两个输出支路宽度增加；主从内部支路不变 | 不作为此次内部耦合修复的首选 |

## 真正改变关键内部结构的候选

以下简名全部加后缀 **BWP12T30P140**。优先级是结构筛选结果，不是端压通过结论。

| 优先级 | 移位DFF候选 | 普通DFF候选 | 替换条件 |
| --- | --- | --- | --- |
| A：先验证 | **GDFCNQMCOD1** | **GDFQMCOD1** | 原引脚功能对应；原厂定义为ECO DFF，前者低有效异步清零，均上升沿触发 |
| B：独立第二结构 | **SDFSYNCNQD1** | **SDFSYNQD1** | SE固定0，SI固定0；D走正常数据口。前者仍为低有效异步清零 |
| C：后备 | DFCNQOPTMAD8 / DFCNQOPTSADD8 | DFQOPTMAD8 / DFQOPTSADD8 | 同功能端口，但更大输入/时钟负载及面积，先不把D8整批装入SAR |

### A：GDF…MCO，保留功能接口，改变内部时钟与反馈

**GDFCNQMCOD1（32条MOS实例，合并并联后28支路）：**

- 普通基线的两级 `CP→clkb→clkbb` 不再原样使用；部分传输和主锁存支路直接由 CP 控制，另有独立反相支路。
- qf_x 的 NMOS复位串联支路改变了控制顺序：基线靠 qf_x 的管栅接 qf、下面接 CDN；此候选靠 qf_x 的管栅接 CDN、下面接 qf。改变了第一类事件的直接耦合位置。
- qf反馈采用传输门连接到额外反相节点的结构，而非原先完全相同的时钟控制串联反馈。
- **仍有 mq_x—内部节点—mq控制管—CDN控制管—VSS 的主锁存下拉链**，所以不能预先保证解决第二类下冲。PMOS等其他路径仍可耦合到qf，不是移除了所有耦合。

**GDFQMCOD1（28条MOS实例，合并后26支路）：**

- 从锁存反馈由基线的串联PMOS/NMOS反馈改为反相节点 `net71` 与 qf 之间的传输门结构。原 `net086` 所在的两PMOS反馈栈不再以原形态存在，直接针对第四类问题。
- 主锁存反馈仍有串联内部节点，且由 CP/独立反相支路控制，第三类风险不能仅凭拓扑宣告消失。
- 库原文还有两只D/S短接的MOS，属于原生实现的一部分；没有删掉这些电容性负载来制造更理想的候选。

代价：手册TT25°C下，CP引脚电容从基线约 **0.490 fF** 增至 **3.41 fF**，约 **7倍**。需要保留真实时钟驱动负载验证，不能因为当前理想时钟能驱动就忽略。单元宽度：移位2.52→3.36µm，普通2.10→2.94µm；不是7倍面积。

### B：SDFSYN…，主从之间增加缓冲隔离

- `SDFSYNCNQD1` 为42条MOS实例，`SDFSYNQD1` 为38条；保留扫描输入，但SE=0时使用D。
- 基线主从之间的直接互补传输门被缓冲/时钟控制级替代；主锁存反馈控制也由缓冲后的节点驱动，而非原mq直接驱动。这是内部锁存结构变化，不仅是加扫描MUX。
- 仍存在串联源节点，且异步清零版的从锁存复位支路仍可产生耦合，不能预判其更安全。
- **SDFSYNCNQ名字里的SYN不等于同步清零。** 原厂把它列在异步清零扫描DFF组，CDN=0时不依赖CP清零。真正同步清零的 `DFKCNQ` 见手册页232，不能直接替换现有异步复位移位链。
- 手册CP电容约0.670/0.667fF，低于GDF候选，但面积更大。新增SE/SI必须固定到确定电平，不悬空。

### C：OPTMA / OPTSAD，内部实现变化大，但目前代价不合适

原生网表包含额外内部时钟相位、数据通路和反馈结构，确实不同于基线；但所比较的非扫描D8版OPTSAD与OPTMA在合并并联管后连接图完全相同，区别为3个内部支路的尺寸/并联实现，不能当作两种独立拓扑。非扫描普通版只有D8：单元宽度6.72µm，异步清零版7.84µm；D输入电容约2.5fF，明显高于基线约0.64–0.66fF。因此保留为后备，不先用大驱动单元掩盖定位问题。

## 不列入第一批的其他选择

- 普通SDF/EDF/MUX系列：输入选择或使能不同，但关键反馈栈仍保留；附加逻辑改变激励，不能当作已消除内部耦合。
- OPTB扫描版：D1与对应普通扫描D1的合并并联连接图完全相同；普通版有8个、异步清零版有6个内部支路的尺寸差异。不是首选的新恢复拓扑。
- 双输出Q/QN：额外反相输出不能自动修复主从内部节点。
- DFKCNQ：同步清零，不等价。DFN系列：下降沿，不直接替换。异步置位或置位/清零双功能：需额外保证初始化与控制优先级，当前不扩大范围。
