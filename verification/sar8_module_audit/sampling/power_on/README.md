# SS 冷角：电源从零启动的最小对照草案

仅本地准备，**未注册、未运行、未经过 Spectre 编译**。复用已冻结的真实 Bootstrap + 完整 CDAC 夹具、固定参考最终级、N4 复位和实际采样时钟路径；不改 MOS、架构或既有结果。它不是 POR 实现。

准备两例，彼此**仅一个 VDD 源行不同**：

| 草案 | t=0 核心电源 / DC 求解 | 核心电源后续 |
| --- | --- | --- |
| `dc_core` | 已为 0.81 V，采样时钟低；允许电路自然形成 DC 储能 | 始终 0.81 V |
| `ramp_core` | 0 V；输入、参考和外部预置命令也从零开始 | 31.1–41.1 ns 从 0 升至 0.81 V |

首例是已上电 DC 对照；第二例才含有限电源爬升。两例均须读取实际初始 Cboot，**不预设它已经充满或严格为零**。旧高相位 DC 案例从 t=0 就处于采样高相位，未观察到首个开启沿；本草案的两例采用相同低时钟前序，不能冒充对旧首帧故障的原样重现，也不重跑 low60cold。

| 绝对时间 | 两例共有的外部测试台条件 |
| --- | --- |
| 0–31.1 ns | SAMPLE=0；模拟输入源、参考高源、Q128 中需为高的边界命令均为 0 |
| 31.1–41.1 ns | 上述外部源一起线性升至原有初值；VDD 仅在 `ramp_core` 中同步爬升 |
| 41.1–101 ns | 电源及偏置已到最终值，SAMPLE 仍为低；平台 59.9 ns |
| 101–101.1 / 141–141.1 ns | 首个正式采样窗口的上升 / 关闭沿，保持原值 |
| 141.1–201 ns | 正常周期的 59.9 ns 完全低电平平台 |
| 201–201.1 / 241–241.1 ns | 后续帧的上升 / 关闭沿，保持原值 |
| 260 ns | 结束观察 |

共同的模拟输入/参考/边界命令启动顺序是本草案新增的**测试台假设**，两例完全相同。它避免在 `ramp_core` 的零电源 DC 点仍外加原先的 0.855 V 输入、0.9 V 参考和高命令。41.1 ns 后恢复原有电平；100.2–100.3 ns 的输入翻转和其余源波形尾部逐字保留。首个正式窗口输入差分为 −0.81 V，后续帧为 0 V；后者不能用于证明另一极性满幅建立合格。

外部时钟保持低电平直至 101 ns 的做法复用了已有 low-phase 测试前序。它要求外部测试环境等待，**没有在 ADC 中设计电源检测、POR、时钟屏蔽或首帧有效逻辑**。斜坡持续 10 ns、放置在 31.1–41.1 ns，仅用于形成可审查的首个诊断场景；不是已批准的电源上升范围或启动延迟规格。预充在爬升过程中就可能开始，不能只用斜坡结束到开启的间隔代替真实充电过程。

最终测试点仍为 SS / 0.81 V / −40°C，TT 无源；**0.81–0.99 V 工作电源合约保留**，未用降低最高电源来规避过压。此次草案不覆盖整个电源范围。参考最终 0/0.9 V、每路 50 Ω / 4 pF，输入每路 50 Ω；外部源理想，无噪声、失配、PEX。固定 Q128 高命令是截断接口的外部理想源，不是已实现的参考复位/POR 逻辑。

测量草案 `review_power_on.py` 将两帧分开输出：

- 原生 SEQ_SAMPLE 相对瞬时半 VDD 的开启/关闭事件；启动爬升中的额外事件单列。缺失、重复或关闭晚于固定保持点时，不制造有效获取窗口。
- 初始、31.1、41.11、80、100.99、200.99 ns，以及各帧实际开启前 10 ps 的 Cboot、BBOT、CTRL、G−VIN、M2/M8 与两只主开关电流。
- 每帧实际关闭前 0.2 ns 的差分建立误差；固定 141.8 / 241.8 ns 的保持值；同时保留相对名义接口关闭沿 141.05 / 241.05 ns 输入的误差，以及相对当前输入的原始误差。
- 关断前至保持点的净电压变化、输入端点变化；该净变化包含继续建立、馈通和注入，**不命名为纯沟道电荷注入**。动态电流也不直接换算 Ron。
- 全程 237 MOS 的 1422 条原生端压记录、收敛/CMI 日志，以及模拟源相对核心电源的启动电平暴露。源高于核心电源只是顺序证据，须结合具体器件端压判定。

启动误差预算、最晚首个有效帧、最短等待、允许斜坡范围均保持未知；既有 ±0.25 LSB 仅作为共享静态诊断线。草案不依据这一条线单独宣布启动或整机合格。
