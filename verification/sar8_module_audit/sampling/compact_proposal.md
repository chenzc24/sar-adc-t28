# 小型采样提取提案

原2506器件/1831MOS壳版保留为本地未编译草案，主聊天未批准运行。
本文件只提出新边界和源网表计数，没有生成下一版电路。

| 保留部分 | 原始实例数 | MOS | MOM | 电阻 |
| --- | ---: | ---: | ---: | ---: |
| 两侧完整Bootstrap | 28 | 26 | 2 | 0 |
| XSEQ.XB最终真实缓冲级 | 4 | 4 | 0 | 0 |
| 完整CDAC及参考通路MOS | 50 | 32 | 18 | 0 |
| 32路参考栅极末级CP/CN及原串联电阻 | 384 | 64 | 0 | 320 |
| N4比较器 | 11 | 11 | 0 | 0 |
| 两个rx2接收缓冲 | 8 | 8 | 0 | 0 |
| PR/NR直接组合逻辑负载 | 29 | 24 | 5 | 0 |
| 原比较器输出/时钟MOM | 3 | 0 | 3 | 0 |
| 合计 | **517** | **169** | **28** | **320** |

计数是源网表实例数，MOM/multi没有展开。320个电阻是32路栅极每路10个
真实PDK串联段；这里不将其合并为理想电阻。所有保留器件的参数、连接和
组映射以SHA固定在compact_proposal.json，避免再复制大份几何清单。

位链、寄存器、时序环和参考字存储/复位链全部移除。参考只保留实际末级
驱动及开关，末级输入按已知采样preset给定：BP0..6=0.9V、BP7=0V，
BN0..6=0V、BN7=0.9V。给定作用于上游驱动已去除的32个B输入节点，不直接
钳住参考栅极输出或CDAC底板。该台不验证转换/复位顺序。

SEQ_SAMPLE保留原10个终端连接，TOPP/N各保留12个，COMP_P/N及PR/NR各保留
8个；按实例、终端和模型排序后与原图一致。接收器再下一级RAW/DATA的
负载会被切掉，必须记录其差异，不能称为完整接收链瞬态等效。

时钟切在XSEQ.QUAL，保留XSEQ.XB四只管和完整Bootstrap时钟负载。此处原
上游驱动不保留，可在明确的模块输入端回放QUAL或施加诊断PWL。现有紧凑
导出没有QUAL波形，因此现在不能宣称已复现整机物理开启/关闭沿。正式
外部101ns/141ns合同保留，后续由主聊天审核回放来源及SEQ_SAMPLE实际沿，
不把减少上游延迟造成的边沿移动当作采样改善。

N4的CMP_CLK在去除原控制器后成为无原驱动的模块复位输入，固定0V。
比较器输入器件、复位支路、输出MOM及真实接收器均保留。直接PR/NR负载
通过保留X004/X005/X006这三个组合子电路闭合，不再反向扩展到整个异步环。

下一步历史对照名称固定为“短低相/长低相”。高相DC加短低相具有101ns
开启沿，已经不同于历史零预充失败；原始首帧另保留为故障证据。两者的
时钟/参考初态差异和新的切口需要复现验证，不能提前声称严格Boot单支路因果。

本地核对目标是517实例/169MOS计数、组映射SHA、关键节点直接扇出以及
所有理想边界的原驱动已移除。运行前还需主聊天审核RAW/DATA输出终止、
时钟回放与独立preset真值。本轮不生成更多网表或运行文件。

本地核对已通过：八组计数/映射参数SHA、517实例/169MOS合计、七个关键
节点终端集合、34个无原驱动的输入边界（32个参考B输入、QUAL、CMP_CLK），
以及RAW/DATA丢失扇出计数。原壳版生成物与manifest SHA仍逐项一致。
