唯一新增观测为 [transition_observe.py](transition_observe.py)：

- CP、D、CDN 增加原生 30%/70% 间隔与明确 `/0.50` 查表坐标，保留各交点括区和原有 10%/90% 时间。
- 内部 clkb／clkbb／mq 增加同一阈值观测，**不赋予库输入引脚的查表坐标**。
- 与冻结直连／2 kΩ 比较 5 ns 原事件的实际时刻、10%/90% 边沿、MM64 峰值／时刻和严格失败对数；完整 raw export 仍支持原方法的电流／分相位电荷回顾。
- 缺失或多重交点输出 unknown；不伪造单一边沿。Q 有效负载、全部条件时序和正式模型配套仍未核定，整机合格值保持空。

原启动参数、gear2only、maxstep 10 ps、容差 deck 均保持。deck 的 `reltol=1e-6` 与旧日志有效值 `1e-7` 要区分；本例运行后须读取原生日志核实有效设置，不能只靠 deck 声称一致。
