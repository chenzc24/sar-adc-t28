## 已有波形说明了什么

来源为完整 FF、0.99 V、−40°C 的 30060 个原生点。回收文件、解压后的
逐字节 SHA、源运行注册输入和已知 raw SHA 均已核对；没有重采样或调整时间轴。
详见[数值与原生括区](usage_evidence.json)。

| 信号 | 10–90% 边沿范围 | 全历史摆幅 |
| --- | ---: | ---: |
| 外部 CK／D／RST 命令 | 16.000 ps | 0–0.990 V |
| DFF CP（CK）引脚 | 2.773–2.801 ps | −0.021115–1.010721 V |
| DFF D 引脚 | 3.164–3.382 ps | −0.020333–1.010180 V |
| DFF CDN（低有效清零）引脚 | 3.261–3.481 ps | −0.034742–1.026054 V |

阈值按本角 0.99 V 的 10/90% 定义，同时保留 20/80% 测量；交点在相邻原生点间线性估计。
这些是本测试台观测，不能当作库的 slew 定义或表征合格结论。两级标准反相器
将外部命令整形成更快的引脚边沿；输入摆幅也包含实际驱动和反冲共同作用。
尚不能把 MM64 内部下冲唯一归因于 CK slew。

## 只改变 CK 输入串联阻抗

对照将 CK 条件驱动输出与 CP 引脚之间从直连改为理想 **2 kΩ** 串联电阻。
该值是一个可见 RC 效应的诊断选择，没有已知库表推荐依据；实际 slew、摆幅、延迟
和静态电平都要重新测量，不能预先断言一定变慢或合格。D、CDN、Q 负载与原生库单元不改。
原外部采样契约／所有命令 PWL 保留，内部 CP 到达时间允许产生并记录实际变化。

## 运行后先看什么

1. 小台基线先复现原 MM64 事件和 Q 状态；峰值／时刻容差 1 mV／10 ps 只是建议的
   复现门槛，不能替代严格端压筛查。失败先查边界，不能直接解读对照。
2. 测实际 CP／D／CDN 的 slew、摆幅和 Q 延迟；原始相位检查保留复位重叠阶段。
3. 同时比较 MM64／MM65 六端对、内部节点负偏、事件峰值和保持阶段恢复；检查
   六节点 KCL 与各端流，区分切换电荷交换和持续电流的证据。
4. 保留全部残余超限、CMI、源功及建立／复位问题，不以单个峰值下降宣布修复。

本对照只回答输入接口对内部应力的敏感性。它不认证全库、完整异步控制器或 ADC，
也不意味着新增理想电阻已有可采用的器件实现。
