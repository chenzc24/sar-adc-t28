# 唯一下一项建议：调整X020的NMOS栈次序

建议先只交换X020私有NAND的两只NMOS栅极：LIVE接靠N的MN0，Q1接靠地的MN1。
本文件是方案说明；没有新网表包，也没有远端修改。

| 器件 | 当前 | 建议 |
| --- | --- | --- |
| 上管MN0 | D=N、G=Q1、S=MID、B=VSS | D=N、G=LIVE、S=MID、B=VSS |
| 下管MN1 | D=MID、G=LIVE、S=VSS、B=VSS | D=MID、G=Q1、S=VSS、B=VSS |
| PMOS两支路 | MP0由Q1驱动；MP1由B_PM驱动 | 保持 |

当前事件中，Q1早已为高，LIVE才从低变高。现有栈让上管先导通、下管后导通，
因此MID预先充到约0.85V；LIVE上升后先释放MID储能，N直到后面才有强吸收电流。
交换后，事件前下管已导通，预期MID接近地，上管由LIVE接通时可直接建立N下拉。
两只串联NMOS的静态逻辑条件仍为Q1与LIVE同时高；PMOS功能和外部采样接口不变。
实际预充、电荷耦合与动态行为必须由PDK瞬态验证。

这是比继续扫CMID更直接的结构变量：已有减半实验使N下拉提前约1.5–1.8ps，
N过冲改善34.9%，但峰值时MID仍高，且MP1注入没有消除。它支持优先处理MID的
初始连接状态。直接换输入栈也会使LIVE对N出现新的栅漏耦合，未保证一定通过。

**功耗边界要明说。** 第一次若执行该单变量试验，先保持half的floor电阻支路，
以便将改善归因于栈次序；约24.7µW低态静态供电功耗仍在，不能宣称低功耗修复。
若N过冲获解决，再将三电阻偏置作为独立变量退出或用无持续直流通路的互补驱动
替代。不得把撤偏置与换栈合成一个无法归因的试验，也不得默认撤偏置后栅端安全。
此处仅建议下一项换栈，不另行准备后续驱动方案/扫描。

需要保留的观察：MP1栅端、N、MID全史电压和全部原生CMI；N/MID各端电流/KCL；
QUIET边沿数/延迟；VDD及边界源能量。先核对当前LIVE上升事件，再检查Q1切换、
复位和后续周期，避免只是把同一储能问题移到另一个输入沿。高低供电范围、采样
窗口和关闭沿均不变。只有当前首事件通过，也不能宣布完整控制模块或整机通过。
