## 实际契约

由原始`sar8p_sr`及两组实际INV/NAND连接提取并枚举稳定解：

`RB=¬R`；`SN=¬(S·RB)`；`QB=¬(RB·Q)`；`Q=¬(SN·QB)`。

| R=CLOCK_RESET | S=CLOCK_SET | 稳态Q/QB |
| ---: | ---: | --- |
| 0 | 0 | 保持：0/1或1/0 |
| 0 | 1 | 置位：1/0 |
| 1 | 0 | 复位：0/1 |
| 1 | 1 | 复位：0/1 |

因此本拓扑的**静态R支配**来自实际资格连接；动态重叠、传播和复位优先性仍须本次原生测试。
提取过程同时验证原始NAND及栅位互换后的静态NM串联／PM并联结构，未套用普通SR的非法输入规则。
详细连接及稳定解：[contract.json](sr_cycle_v1/contract.json)。

| 区间/ns | R/S | 预期Q/QB | 覆盖 |

| 1–2 | 0/0 | 0/1 | 释放，保持0 |
