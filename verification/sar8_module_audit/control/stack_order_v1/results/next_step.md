# 唯一下一项建议：局部耐压互补逻辑，退出三电阻直流偏置

将X020及其实际驱动/接收接口作为一个局部耐压边界，评估已核实的T28普通
1.8V器件 `nch_18_mac/pch_18_mac`。保留LIVE靠N、Q1靠地的栈次序；
退出RPU0/1/2持续上拉支路，恢复互补逻辑的低态关断方式。保留0.81–0.99V
供电范围，外部采样窗口和关闭沿不动，不新增理想偏置电源。

这是一次局部门单元重构的建议，不是继续扫电容或电阻。此处没有新包/远端操作。

依据是两类问题同时存在：

- 换栈使MID预放电生效，但LIVE既有下冲导致上管VGD达到−1.000869V；
  Q1既有过冲又使下管VGS/VGB达到0.991334V。0.99V供电同时等于当前核心管
  诊断上限，数mV耦合即可越线。单独减少某一路注入没有为所有端压建立裕量。
- 正栅偏置使所测MP1栅端安全，却形成VDD→三电阻→B_PM→栅串联电阻→
  LIVE下拉驱动的直流路径，局部低态供电约24.5–24.7µW。撤去三电阻支路
  才能去掉这部分持续电阻负载；更换电容本身不能实现该目标。

需要在同一个方案中覆盖以下接口，避免只提升接收管耐压而遗漏仍暴露的驱动端：

| 边界 | 方案中需处理/观察的对象 |
| --- | --- |
| LIVE、Q1输入 | X001/X019的实际输出驱动端，以及接入X020的栅端；双向反冲与栅负载一起验证 |
| X020内部 | NAND四管及N后的恢复反相器；原MID次序保留，三电阻直流支路退出 |
| QUIET输出 | 真实RC/逻辑负载及其首级接收管；检查高/低边沿的端压暴露 |

局部替换范围须由实际连接和联立端压确定。当前已证实的是本报告所列端压；
没有测齐的上游/下游管不应被预先宣布失败或通过。输出暴露端需纳入观察，
超限时纳入耐压边界，不能只改MN0/MN1后直接宣布闭环。

器件几何沿用已核实的CDF合法起点，再按真实负载决定尺寸/并联数，不能将核心
30nm沟道长度直接套给IO模型。已有审计确认普通IO默认单元为L=150nm、
W=320nm；原生模型曾接受这些参数，但这不是版图DRC。见
[已有器件审计](../../../../sar8_physical_repair/io_cdf_audit.json)和
[此前低压逻辑测试](../../../../../docs/sar8_physical_repair.md)。

电阻串联栅控是否仍有必要，应在耐压单元内根据瞬态决定，不再以持续直流分压
作为保护前提。使用互补结构只能去掉该电阻偏置路径；漏电、短路瞬态和新负载
功耗仍要测，不能声称所有静态功耗归零。

建议后续验证顺序是先在实际负载下检查FF事件全端压、QUIET边沿/脉冲与五源
能量，再检查SS/0.81V冷角速度、复位和首事件状态。既有FO4测试中IO在SS冷角
约202.6ps，核心约33.7ps，说明耐压替换有明确速度代价；这些旧FO4数字不等于
本新负载的延迟，也不能据此定尺寸或直接全量替换控制器。

该方案尚未验证。进入完整控制/整机前，仍需覆盖Q1其他切换、后续周期和真实
接口负载。本次只交付这个局部修复方向，不准备多个候选或继续机械扫描。
