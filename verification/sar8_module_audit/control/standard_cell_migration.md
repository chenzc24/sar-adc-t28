## 3. 必须保留的状态与时序

**两个 SR 保留原连接。** `RB=¬R`、`SN=¬(S·RB)`、`QB=¬(RB·Q)`、`Q=¬(SN·QB)`。
`R=S=0`保持；`R=0,S=1`置位；`R=1`时Q清零，包括R/S同时为1。
这是实际资格网络推得的静态复位优先，不能换成普通SR的非法输入约定。
现有CQB属于显式外部存储负载，候选冻结前确认保留方式；不得接到库单元隐藏管节点。
已有10ns双向序列可直接复用于标准门候选，覆盖置位、保持、从Q高复位和两种重叠释放顺序。

**24个寄存器保留原合同。** 原传输门连接表明主锁存器在CK低时采样、从锁存器在CK高时接收，
对应理想开关意义的上升沿捕获；RST高经两个锁存级异步清Q。
因此`DFCNQD1`仅是待核实候选，暂定映射为`D→D、CK→CP、¬RST→CDN、Q→Q`。
不能从CDN名称直接宣布等价。位序列8个、码字8个、参考捕获8个全部列出；
参考MSB原有数据／输出反相必须保留，确保复位后Q7=1、Q0…6=0。

**握手与模拟接口分别核对。** 比较器输出接收→RAW/DEC资格→PHI_W写入→PHI_U更新→
比较时钟复位／重启的顺序不变。参考的早／晚捕获请求、分步复位及两方向BBM死区均单列。
RC模块的内部反相器可以标准化，但其阈值、慢输入和清零反馈会改变实际延迟；必须先分配时序约束，
再决定保留RC或采用已表征延迟链，不能直接删掉这些功能。
模拟接收 buffer 与驱动 Bootstrap／比较器的 buffer 仍需验证反冲和实际负载。
外部供电范围、采样窗口和有效关闭沿保持受保护，不因门延迟变化而悄悄调整测试时序。
