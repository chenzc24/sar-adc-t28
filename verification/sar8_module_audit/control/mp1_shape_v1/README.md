# X020 MP1 单支路栅极整形

准备好的唯一实验为 [recipe.suggested.yaml](recipe.suggested.yaml)，建议运行名
`sar8audit-ctrl-mp1shape-v1`。以已逼近原机的 both 台为对照；尚未由本 session
执行 Spectre。不是继续拟合复现，也不是整机通过结论。

只改一条连接并增加一个现有 PDK 器件：

```text
LIVE ─────────────────────────────→ 原 MN1 栅极
  └── rupolym ── B_PM ─────────────→ 原 MP1 栅极
```

`rupolym` 直接复制已使用的 quiet-delay R0：`l=17.13u w=1u m=1 multi=(1)`。
它在当前FF冷角波形中观测到的端压/电流比约9.79kΩ，本轮不拟合或扫描阻值。
不增加电容，MOS模型/尺寸全部保持；栅极动态由原PDK器件电荷求解。

理由：both 中 MP1 是 N 上升期间的主要净注入支路。让 MN1 保持直接响应，
而 MP1 栅极变化受电阻限制，可以检验是否在减小注入的同时，让 MID 放电
先建立。改善幅度、上拉/下拉重叠电流及延迟都由此次仿真测量，不预先保证。

原供电0.99V、外部采样窗口/关闭沿、11路原PWL（含条件漏端偏置）、全部原
MOS参数和其他节点连接保持。共101 MOS、19无源器件；无新增电压源或时钟。
只为 X020 复制局部 NAND/AND 定义，其他复用该通用单元的逻辑不变。

保存62路电压、438路电流、14个关键KCL节点，覆盖新B_PM、LIVE、N和MP1端流，
并补存局部VDD电流。重点看：N正峰值及相关端压、B_PM下冲、MP1负电流/电荷、
QUIET边沿数量与延迟、KCL和实际告警。局部VDD读数不代表完整ADC功耗，原来的
理想条件偏置源仍然存在。

原1mV/5ps门槛用于验证**未改电路的隔离台复现**。本实验有意修改内部响应，
应评估过冲降低与延迟/电流代价，不把对原尖峰的较大偏差判成复现失败。
冻结分析器仍只报原始数据、`acceptance_pass=null`；整机及其他节点的CMI
是否关闭，需要后续电路验证。

本地检查确认：仅MP1栅连接改变、仅新增一个PDK电阻、原MOS参数/其他连接及
全部PWL字节不变，所有声明输入SHA匹配；扩展测量已通过一次合成原生数据的
冻结分析器接口执行。尚未作Spectre电气验证。资源沿用both：单线程、仿真
RSS≤1GiB、分析≤256MiB、原始输出≤1GiB、回收≤32MiB，由主聊天串行执行。
