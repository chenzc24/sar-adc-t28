## 原整机的真实 PRE 驱动边界

`pre_driver_boundary.json` 从原整机冻结本地导出定位，带有源 SHA；不是当前 OA 读回。

- PRE 原节点：`XDUT.XREF.XDRV0.GNNPRE`。
- 实际驱动：`XREF.XDRV0.X025`，master=`sar8p_inv`。
  其 MN/MP 的 **drain pin1** 接 PRE，均为原核心管，N/P W=0.5/1 µm、L=30 nm。
- 原负载：GNNAN/GNNAP 的 **gate pin2**，没有其他 PRE 栅极负载。
- X025 输入为 `XREF.L0`，由 `XBBM0.X004.X001` 驱动；该节点同时接 X025 与 GPPAN/GPPAP 的栅极。
  PRE 与 L0 反相。后续真实驱动台需要保留这些共享扇出与实际端口，不能只增加一只空载 X025。

本次直接用理想 VPRE 驱动新 A，没有实例化该核心 X025。
因此源端功只是对理想输入边界的测量，不能代表 X025 的实际电压、速度或功耗，也不能宣布真实接口合格。
