# RC1／HD：下一项接口对照

**准备一个耐压模拟接口候选，尚未仿真。** 不再扫驱动档位。保留原数字库、供电范围、采样窗口与关闭沿、LD及完整物理负载，仅将 HD 的 RC1 接口作为一个结构变量替换。它包含协调的器件与被动网络变化，不能用于单管归因。

## 现有故障的三个暴露点

| 位置 | 已测事实（D1P25，FF／0.99V／−40°C） | 修复须覆盖 |
| --- | --- | --- |
| RC1 正相 | 43.037ns 达 1.025818V；领先区 clear 漏端净电荷 −0.270fC | clear 注入与核心接收管输入端压 |
| RC1 负相 | 48.004ns 达 −16.237mV；领先区 clear 漏端净电荷 +0.105fC；clear 的绝对 Vds 达 1.006237V | 负向恢复及 clear 自身耐压 |
| HD 回流 | 最坏 Vgd 时 RC1=−16.062mV、HD=1.011603V；NAND 门端 −59.830µA、接收器漏端 +59.830µA | 输出承受能力与后续核心 NAND 输入 |

电流正方向为流入器件。三个现象有关联；不能只把 RC1 或 HD 单节点峰值变小当作端压修好。上述电荷为声明区间内总端口积分，未分解为本征 Cgd／沟道电流。

## 只比较两种改法

| 方案 | 实际连接 | 收益与代价 | 判断 |
| --- | --- | --- | --- |
| A：保留核心管，加无源隔离 | RC1→串阻→原 X005 栅，增加接收端电容；HD 同样串阻滤波后进 NAND | 能整形交换电流；增加 RC 延迟。但 clear 的 Vds 应力仍在，核心 X005 自身输出仍可能越轨；新浮动栅也会接收自身回流。在 VDD=核心筛查上限时，低通滤波没有独立的端压余量 | 不准备。可能转移应力，不能覆盖三个暴露点 |
| B：耐压模拟接收＋有余量的核心输入 | RC1 clear 改为已有 IO PMOS；RC1→IO N/P 接收器→HD_RAW→被动偏置滤波→HD→原生 NAND | 让直接接触 RC1／HD_RAW 的 MOS 使用实际 IO 模型；被动网络给核心输入留余量。代价是直流负载、摆幅压缩、IO 驱动和复位变慢；必须检查逻辑与功耗 | 仅准备这一项 FF 候选，不宣布修复完成 |

方案 B 没有替换纯数字库单元：X006、X002、NAND 和所有其他原生逻辑保持原样；自定义的是 RC 模拟接收与复位接口。clear 和 IO 接收 N/P 的完整器件记录来自本项目已用的 GNNCP／GNNCN，均为 L=150nm、W=320nm、N/P multi=2/4；没有编辑标准库内部或复制 PDK 模型内容。clear 使用 P 的 multi=4。

## 候选的明确连接

```text
RC1 ── IO inverter ── HD_RAW ── R ── HD ── original native NAND
                                      │
                         VDD ── 2R ───┼─── 2R ── VSS
                                      │
                                     4C1
                                      │
                                     VSS

RC1 的 MP_CLEAR：核心 PMOS → 已有 IO PMOS；原 clear 栅串阻保留。
```

R 复用已存在的 rupolym 单元，2R 用两只相同单元串联；4C1 复用原 MOM 几何、multi=4。原 R0/R1/C0/C1、MN_CLEAR、X002/X006 及真实扇出保留。移除 4 只原生接收 MOS，增加 2 只 IO MOS、5 只电阻和 1 只电容，另改 1 只 clear 的实际模型/尺寸；**192 条其他叶记录逐项相同，HD 外部全部相同。**

## 为什么选这个被动比例

无直流栅电流、输出源足够硬的条件下：

`VHD = 0.5·VHD_RAW + 0.25·VDD`，低/高电平为 `0.25/0.75 VDD`。

旧 IO-C 实验的 FF 输出曾为 −0.305699…1.371385V，SS 为 −0.274963…1.113774V。因此“换 IO 后直连核心输入”并不成立。仅把这些旧端点代入上式，FF 得到 0.094650…0.933193V，SS 得到 0.065019…0.759387V。**这只是选比例的反例检验，旧负载不是新接口，不能作为新波形的上界。**

原生积分给出的 C1 量级约 4.953fF、R 约 9.791kΩ。4C1 约 19.811fF；硬输出源且忽略 NAND 输入电容时，时间常数约 97ps，1%恢复约 447ps。IO Ron 和实际栅电容会增加传播时间；不能据此保证非交叠或整机速度。

**0.25/0.75VDD 不是实际加载电平。** 用等效 Ron 作直流示意：

`VLOW/VDD = (R+Ron)/(2·(2R+Ron))`，`VHIGH=VDD−VLOW`。

Ron=R 时已收缩为约 1/3、2/3 VDD，Ron 很大时两者趋近中点。若仅举例要求 30%/70% 输入，则须 Ron≤R/2≈4.90kΩ；**这不是本库已经核准的 VIH/VIL。实际 VIH/VIL 目前 unknown**，半 VDD 跨越只用作时序诊断。

硬输出源估算的每腿偏置功耗为 `3·VDD²/(8R)`：0.81/0.90/0.99V 时约 25.13/31.02/37.54µW，尚不含 NAND 中间电平电流、IO 复位和动态损耗。若盲目复制到全部16腿，仅这项就约 0.40–0.60mW；所以本次只测试一腿，不采用为整机方案。

## 本次 FF 台的判读顺序

1. **原契约保留。** 原 HD→0V 的 full-swing 复位结果单列于 `original_full_swing_HD_reset_contract`；三个静态窗口也保留原 HD=0/VDD 的目标、误差和通过状态，不会改成 0.25/0.75VDD 后算通过。RC0/RC1 的原复位目标不变。guard 输入的加载偏置不等于原 rail-reset 通过。
2. **看实际逻辑。** 分三个静态窗口报 HD、HD_RAW、NAND_N、H0、L0 的高低值，以及原 H/L 逻辑观测；检查缺失/重复边沿、误翻转、实际栅非交叠和四个物理参考建立窗口。压缩摆幅只有在真实后级正常工作后才有讨论价值，VIH/VIL 未知仍保留。
3. **看全路径应力。** 原生读取全部 123 只实际 MOS／738 端对及持续时间，core=0.99V、IO=1.98V，不合并旧750项、不放宽门限。既查 RC1/clear/HD_RAW/HD，也查上游 B、AB、未改核心接收级及 NAND 内部，避免转移故障；保留 body 电流及原生告警。
4. **看代价。** 分静态窗口报全台、HD 新接口及原生 NAND 的 VDD 平均电流/功率、被动电阻耗散；这些是内部归属，不能再与全台重复相加。CODE 源负担单独保留；当前 CODE 仍理想，不能据此验收真实控制源。

与基线一致：FF／0.99V／−40°C、0–52ns、原求解设置、完整 CDAC/Bootstrap、比较器复位、其他位静态；理想 CODE/电源/时钟，无噪声、失配、PEX、活动 ADC 判决。该台只决定接口路线是否值得继续，不能判整机修复或 PVT 通过。
