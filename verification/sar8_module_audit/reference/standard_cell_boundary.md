# 参考控制块的标准单元替换边界

按用户方向迁移数字门；C0×4在途结果只保留为诊断证据，不再继续生成自搭门调参候选。
下述为控制任务可用的连接与验收接口，不是已完成替换或新基线。

来源：冻结原始网表 `output/sar8_physical_repair/sar8fix-loaded-ref-ffcold/dut.scs`，
SHA256 `a42e44613b4b1a8a74876a4c996f5bd2bf2e74bf13da6729818ab85bde5a21de`。
当前完整参考切片及负载见 [BBM说明](real_bbm_note.md)。不推断当前 OA 已同步。

## 1. 布尔逻辑可以标准化，内部延迟必须重新测量

参考侧顶层接口仍为 `sar8p_nonoverlap CODE H L VDD VSS`。
这里 CODE 对应整机 `XREF.Q0` 的参考保持字，不是最终 ADC 输出总线；诊断台把它理想驱动。

| 原参考实例/接口 | 原连接及功能 | 标准化边界 |
| --- | --- | --- |
| `XBBM0.X000` | CODE→CB，CB=¬CODE | 普通 INV 候选，保留 CB 的全部实际扇出 |
| `XBBM0.X004` | A=CB，B=LD，Y=L；L=CB·LD | 整个 AND 可用库门或已核实 NAND+INV 实现 |
| `XBBM0.X002` | A=CODE，B=HD，Y=H；H=CODE·HD | 同上，不能仅按最终真值忽略开启/关闭延迟 |
| `X025`、`X008`及普通驱动中间级 | L→PRE=¬L；H→GPNPRE=¬H，后接缓冲链 | 可迁移普通 INV/buffer，但需保留真实前后级负载及电源域 |

控制任务已核实的库与端序见 [最小映射说明](../control/standard_cell_minimal_mapping.md)：
`tcbn28hpcplusbwp12t30p140` 的 `INVD1BWP12T30P140` 为 `I ZN VDD VSS`，
`ND2D1BWP12T30P140` 为 `A1 A2 ZN VDD VSS`。这些是可复用候选，不代表参考负载已通过，
D1也不是冻结驱动档位。

本参考源 AND 内部为 `X000(A B VDD VSS N)` NAND、`X001(N VDD VSS Y)` INV。
原 NAND 的输出邻接下拉管 MN0 接 A；控制侧已核实标准 NAND 的输出邻接管接 A1。
因此优先保留动态对应：L路 CB→A1、LD→A2；H路 CODE→A1、HD→A2。
不能直接照抄控制侧另一个 wrapper 的 A/B 交换。互换输入不改变真值，却可能改变边沿行为。
整门替换时原内部 CMID 随原实现退出，不接到标准单元隐藏节点；外部 RC 网络另行保留。

## 2. RC+clear 是带状态的延迟块，不是普通布尔等价

`XD_LD(CB VDD VSS LD)`、`XD_HD(CODE VDD VSS HD)` 均为 `sar8p_delay_bbm`：

- R0：A→RC0，C0：RC0→VSS；X002：RC0→B反相。
- R1：B→RC1，C1：RC1→VSS；X005：RC1→Y反相。
- X006：A→AB反相；MN_CLEAR：RC0→VSS，栅接AB；MP_CLEAR：VDD→RC1，栅接A。

A变低时两条 clear 路径使 RC0回0、RC1回VDD、Y回0；A变高后解除clear，
经两段RC才使Y变高。需要保留的是**延迟开启、快速撤销与可重复复位**，不只是Y=A的静态真值。
库延迟单元也须核实相同契约，不能凭名称或单个名义延迟直接替代。

X006属于布尔反相，但驱动实际clear栅负载；X002接慢RC输入，X005接RC1及其过冲，
均须检查标准单元允许的输入slew、端压和真实负载。
目前FF RC1正峰使X005绝对Vgd达到1.062566 V，负向阶段MP_CLEAR绝对Vds也达到1.008802 V。
因此仅换接收反相器不能宣称整个延迟块过压已修好。clear管和RC储能元件不能当作普通逻辑门抹去。

## 3. 模拟侧驱动按电源域与负载选择

| 接口 | 必须保留的实际负载/要求 |
| --- | --- |
| CODE | BBM的7个MOS栅端及HD腿R0输入；上游原存储器仍未恢复，不能最终用理想CODE源证明驱动能力 |
| H | GNP A的N/P栅、X008的N/P栅，共4栅；X008输出再驱动GPN A两栅 |
| L | X025的N/P栅、当前单级IO GPP的N/P栅，共4栅；X025输出再驱动GNN A两栅 |
| GNN/GNP/GPN/GPP最终驱动 | 原40段Rgate网络、真实CDAC参考开关栅及反向耦合，不用统一拟合电容替代 |

当前 GNN ABC 与单级GPP采用IO器件；H链及X025含核心器件。
普通中间buffer可以迁移标准单元，末级及受模拟回灌的级必须核对实际域和负载，
不能一律换核心D1，也不能因MOS额定1.8 V便认为1.8 V IO标准单元可在0.81–0.99 V工作。
不擅自新增1.8 V电源或电平转换。电源范围、0/0.9 V参考与采样关闭沿仍受保护。

Bootstrap的自举/隔离/模拟采样MOS、CDAC电容及参考模拟开关、比较器均不属于这次普通数字门映射。
标准单元的布尔/时序模型也不替代器件级端压检查，真实库SPICE、PVT模型与`.lib`版本须对应。
保留核心/IO各自原筛查和CMI，不因使用foundry单元而关闭门禁。

## 4. 给控制任务的时序与测量契约

| 稳定状态 | GNN0 | GNP0 | GPN0 | GPP0 |
| --- | ---: | ---: | ---: | ---: |
| H=1、L=0：高参考选择 | 0 | 0 | 1 | 1 |
| H=0、L=1：低参考选择 | 1 | 1 | 0 | 0 |
| H=L=0：互斥间隙 | 0 | 1 | 0 | 1 |

必须检查实际负载栅极的四个先后关系：

- 选高：GNN下降先于GNP下降；GPP上升先于GPN上升。
- 选低：GNP上升先于GNN上升；GPN下降先于GPP下降。

半VDD交点只是现有诊断读数，不能把0 ps当最终安全裕量，或将其等同MOS开始/结束导通。
完整BBM基线SS的H/L虽有185.134 ps正间隔，N侧后级却为−191.747 ps；
相反参考总D电流约10.863 µA，说明必须把库门延迟与后级核心/IO延迟放在一起验证。
CODE负载还包含RC充电：FF诊断中C0×1/×4的上升事件绝对电荷约14.40/29.09 fC；
它不是固定线性门电容，C0×4亦未被采用为新基线。

控制owner接入时保留：

1. 外部采样窗口/关闭沿、0.81–0.99 V电源、参考/输入范围和原逻辑极性；不强行对齐标准单元后的内部沿。
2. CODE/H/L、四路真实栅压、底板/参考、电流/KCL、输入负担、独立源功和所有真实器件端压。
3. 高/低激活与撤销、两腿RC0/RC1及延迟输出的复位；缺失/歧义边沿、未复位和截止前未建立明确保留。
4. 建立判据在下一CODE边沿开始前结束；边沿后到门半轨之间的残差单列为切换扰动，不重报为稳定高状态失败。

## 5. C0双角结案后应保留的明确约束

C0×4的SS结果已回收：[双角对照](bbm_hdc0_findings.md)。高方向H/L半轨间隔从185.134增至337.295 ps，
但N侧后级仍是−35.697 ps；相反方向总D电流峰值10.863→1.491 µA，不能写成已消除并通。
这组实验只解释接口延迟，不再沿自搭门调参路线扩展。

**互斥预算必须落到实际开关栅端，包含上下游传播差。** 选高的N侧诊断关系为：

`GNP下降 − GNN下降 = (H上升 − L下降) + (H→GNP下降) − (L→GNN下降)`。

| SS现有负载 | L→GNN下降 ps | H→GNP下降 ps | 两路径差 ps | 实测H/L间隔 ps | 末级间隔 ps |
| --- | ---: | ---: | ---: | ---: | ---: |
| C0×1 | 416.557 | 39.677 | 376.880 | 185.134 | −191.747 |
| C0×4 | 412.468 | 39.476 | 372.992 | 337.295 | −35.697 |

因此不能只给标准单元控制块一个“337 ps互斥已满足”的接口结论。
在当前负载下，单按半轨排序就还需超过372.992 ps才得到零以上间隔，之后还需工程余量。
这些是当前拓扑的诊断算式，不是新冻结指标；换库门后传播差、slew和实际导通阈值必须重新核对。
另外三个先后关系同样在四个真实栅端评价，不能只检查H/L。

**开启延迟、撤销和复位分别保留。** C0×4中HD撤销仍由CODE直达AND的快速路径决定，
不应为了增加开启延迟而把撤销也改成同一慢延迟。
HD/LD各自RC0、RC1及延迟输出应在下一次该腿使能前完成复位并留余量；
当前SS的1%诊断恢复分别约40.193/42.342 ps，不能当作所有PVT/连续帧的最短复用规格。
库延迟单元须验证双沿和复位/重入行为，不用上升沿一个延迟数代替整个契约。

**参考建立截止点是下一CODE边沿开始。** 诊断台高状态截止47.995 ns；
迁移后的整机须取实际下一CODE变化起点，不照抄这个测试时间。
当前C0×4 SS两侧高参考在44.048998/44.140323 ns后持续进入1 mV，
低参考在49.364107/48.974242 ns后进入1 mV；属于该52 ns切片结果，不直接移作新控制器预算。
CODE后至栅极半轨之前的注入独立报告，不能用它否定边沿前的稳态建立，也不能把真实扰动删掉。

**负载与电压域不是布尔等价的一部分。** 当前C0×4仍有FF 213/738项严格端压超限；
HD X005过压累计时长增长、CODE负担与复位时间增加，均需在标准化后重测。
输入端既有真实RC充电又有门栅电流；上游实际标准单元驱动和接收端必须一起闭合，
不能以理想CODE源下的功能正确或库名义驱动档位代替。

当前只完成接口整理与旧诊断结案；标准单元型号/驱动档位和延迟块实现由主聊天统一冻结。
本文不创建新实验、不修改库、OA、旧输入或结果，也不授权参考侧自行扩大替换范围。
