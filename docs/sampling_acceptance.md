# 采样验收指标与主采样管宽度判断

现有标称短测支持继续使用1×主采样管，即W=1 µm、L=150 nm。
2×确实改善了4.5 MHz幅值和非基波残差，但尚无指标要求必须加宽。
这取代此前以更多高频裕量为依据的2×候选建议；原理图本来就是1×，
本次没有改电路或启动仿真。结论限于已测的两个正弦条件，不是整机签核。

## 验收口径

8-bit、10 MS/s、差分范围±0.9 V保持不变，LSB=7.03125 mV。
系统ENOB≥7、DNL/INL绝对值≤1 LSB、无缺码和功耗≤1 mW目标不变。
沿用既有项目口径的SNDR≥43.9 dB，不在本轮改变ENOB归一化算法。

| 项目 | 当前验收或记录方式 | 数字的性质 |
| --- | --- | --- |
| 固定等效延迟 | 记录τ和相位，不要求τ为零；绝对时间上限暂未指定 | 时间特性，不并入随机误差RSS |
| 增益偏差 | 不假设增益校准；拟合增益在±0.9 V端点折算误差≤0.25 LSB，即绝对增益偏差≤0.1953125% | 本次暂定的采样模块工程分配，不是8-bit行业定律 |
| 非基波残差 | 报告去直流和基波后的峰值、RMS；与系统共享0.15 LSB RMS失真余量比较占用比例 | 原有全机共享预算，尚未独立分配给采样开关 |
| 联合电压筛查 | 只对齐一个共同固定延迟，保留增益、DC和全部剩余项，样点误差峰值≤0.25 LSB | 沿用原电压额度，重新限定其适用的误差类别 |
| 孔径／时钟抖动 | 20 ps RMS预算不变，不能用确定性延迟拟合值或两个频点的τ差代替 | 原有随机时序预算，本批未测 |
| CDAC建立、比较器offset | 各自0.25 LSB门限不变，仍在相应工作相位直接验收 | 不能通过采样相位对齐来豁免 |
| 整机动态与静态 | 输出码的SNDR/ENOB、DNL/INL、无缺码及功耗单独验收 | 不能由20个模拟保持值的残差代替 |

原始量`held−source(名义时刻)`继续记录，旧的0.25 LSB原始门限结果也保留，
但不再把它作为包含固定相位滞后时的独立动态精度否决条件。
用户若指定绝对触发时刻、通道同步或相位精度要求，需另设时间指标。

固定孔径延迟与逐次孔径抖动的区分见
[ADI MT-007 第3页](https://www.analog.com/media/en/training-seminars/tutorials/MT-007.pdf)。
Ron随输入变化导致非线性建立误差的讨论见
[TI建立时间与失真](https://e2e.ti.com/blogs_/archives/b/precisionhub/posts/settling-time-challenge-and-improvement-tips)。
整机动态指标的定义见
[ADI MT-003](https://www.analog.com/media/en/training-seminars/tutorials/MT-003.pdf)。
这些资料支持误差分类，不替我们规定上述模块分配数值。

## 如何分离并防止过度拟合

在每个频点用已保存的20个观察值拟合DC、sin和cos，分别报告相位延迟、
增益与非基波残差。名义采样点仍为SAMPLE的50%下降沿，保持读取仍为+0.6 ns。

联合电压筛查更严格：每种W只取500 kHz得到的一个τ，原样用于500 kHz和
4.5 MHz两组输入。高频不重新选延迟，不减去增益或DC，不逐样点调整时间。
这只是离线时间基准定义，没有加入硬件／数字增益校准或改变时钟。

设`xτ`是源端拟合正弦平移上述共同τ后的值，则联合项为`held−xτ`。
增益、DC、非基波是联合项的组成部分，不能把联合项与这些分项再RSS相加。
非基波残差也含历史、动态和数值成分，不等同于纯静态INL或随机噪声。

## 现有结果

共同条件为T28 TT、0.9 V、27 °C、10 MS/s；每组24帧，4帧预热加20帧观察。
原生拓扑、L、CDAC、外部时序及Spectre精度一致，只有主管W及派生源漏几何变化。
500 kHz差分峰值为0.8 V，4.5 MHz为精确−1 dBFS的0.8021258443 V，
所以它们不是严格等幅扫频；同一频率内三种W的输入历史相同。

## 1×是否够用与2×是否必要

**当前保留1×为标称开发基准，2×为可选裕量方案，不是必需修复。**
1×最严频点的增益端点误差0.196630 LSB及共同τ联合峰值0.194082 LSB，
均低于0.25 LSB；后者约有22%的名义限值余量。这足以支持现阶段不加宽，
但不是PVT或随机失配的保证。

2×把高频联合峰值降至0.100311 LSB，非基波RMS减少约72.54 µV，
等于0.010317 LSB。这是实测改善，但1×尚未成为当前8-bit标称精度瓶颈。
在功耗差、PVT和失配尚未测量时，不能仅因2×数字更小就把它认定为必要尺寸。
低频结果反而是1×增益及非基波更小；高频关断相关非基波峰值则随W为
17.095／18.399／22.942 µV，不能把加宽理解成所有误差单调改善。

3×相对2×仅再降低约0.001975 LSB的高频非基波峰值，增益略差，
不作为当前选择。这里没有推断哪种W功耗更低。

六组原生记录均为24帧、每帧8次比较／写入／更新且最终码稳定。
500 kHz的2×仍保留一次LTE局部放宽，其他组无该告警；旧原始门限的失败
及波形不被改写。未补跑全码、FFT、噪声、失配、PVT或功耗，整机验收仍未完成。
