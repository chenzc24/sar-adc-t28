# SAR8 首组合龙冻结候选

2026-10-20。候选编号 **SAR8_JOIN_R0_3X_IDEAL_GATE**。
本组按用户选择固定为：现有 T28 Bootstrap、真实 MOM/双轨 CDAC、
**P/N 同为 3× 的参考开关＋理想栅压**、现有 StrongARM、精简原生异步控制器。
不继续比较 2×/4×，不优化 PVT/失配，不改回旧的握手控制架构。

本轮完成的是模块清点、源版本锁定和统一接口合同。**接口适配器与统一顶层
尚未实现，未进行新的联合 Spectre 仿真，不是整机验收冻结。**
机器可读合同：[sar8_join_r0.yaml](../config/sar8_join_r0.yaml)。
源文件/电路指纹：[join_r0_sources.json](../verification/integration/join_r0_sources.json)。

## 1 只选这一组

| 模块 | 本组选定版本 | 本次处理 |
| --- | --- | --- |
| 输入采样 | `sar_bootstrap_canvas_flat_8b`，每侧一套 | 不改拓扑/尺寸；主管 W/L=1 µm/150 nm，T28 1.8-V MOS，Cboot=1 pF，无独立 Cs |
| 电容阵列 | `control_m3.scs` 内的 `cdac8_dr_nominal` | 保留 T28 `cfmom_2t`、每侧 128…1＋dummy；Cu≈4.004 fF，每侧约1.025 pF；名义 m 聚合版 |
| 参考开关 | 同一来源的 `cdac8_dr_sw_b0…b7` | 每 bank 只留 PMOS 高轨、NMOS 低轨；P/N 同乘3，32个声明的 pass MOS；不带旧六管驱动器 |
| 参考栅压 | 理想零输出阻抗边界 | 只理想化参考开关栅驱；不理想化 Bootstrap、比较器或异步逻辑 |
| 比较器 | `sar_strongarm_t28` | 原11管版本，不改W/L；输出/时钟按原生控制器测试台保留额外10 fF负载 |
| 控制器 | `sar_logic_8b_async_simple`，`simple_v2` 导出 | 原21种原生cell；不加EOC、FAULT、输出银行或外部位时钟 |
| 外部边界 | 0.9-V电源/参考，VCM=0.45 V，输入50 Ω/侧，参考50 Ω＋4 pF/轨 | 允许理想外部源；不是管级reference buffer或时钟树完成 |

3×指**并联倍率**，不是把所有MOS单指宽度或沟道长度都改3倍：

- PMOS单位W/L=175/30 nm，NMOS=150/30 nm，bit b 的倍率都是 `3×2^b`。
- LSB等效总W：P=0.525 µm，N=0.450 µm。
- MSB等效总W：P=67.2 µm，N=57.6 µm。
- Bootstrap和比较器的尺寸与该倍率无关。

3×参考开关目前是**网表派生版本**，不能把现有同名OA叶单元直接视为它：
旧OA `cdac8_dr_sw_b*` 仍包含六只真实驱动MOS；本组选定的网表叶单元没有。
本轮不覆盖旧OA，不伪称已保存新3×原理图。

## 2 P/N映射统一

记当前试探码 `CODE = D OR TOKEN`，正残差 `TOPP−TOPN > 0` 保留该位。
物理阵列P侧dummy接VREFP，N侧dummy接VREFN。

| 物理CDAC的高有效请求 | 取自现有控制器 | 稳态含义 |
| --- | --- | --- |
| `PH[i]` | `BN_Hi` | P侧高轨选择为 `NOT CODE[i]` |
| `PL[i]` | `BN_Li` | P侧低轨选择为 `CODE[i]` |
| `NH[i]` | `BP_Hi` | N侧高轨选择为 `CODE[i]` |
| `NL[i]` | `BP_Li` | N侧低轨选择为 `NOT CODE[i]` |

这是**参考选择bank的交叉映射**，不是把模拟TOPP/TOPN、VINP/VINN或比较器
OUTP/OUTN对调。比较器仍是VINP→TOPP、VINN→TOPN、OUTP→COMP_P、
OUTN→COMP_N，CLK接原生CMP_CLK。
顶层的全局 `VDD!` 与显式 `VDD` 必须接同一0.9-V网络，`VSS` 与 `gnd!`
接同一地；不能留下Bootstrap全局供电悬空。

在定义好的采样初态下，理想电荷关系为：

`TOPP − TOPN = VINDIFF + 0.9 − CODE × 1.8 / 256`

离线检查覆盖256个码的映射、互补选择和电荷方程，并覆盖256个码区间的
逐位算术决策。这不是原生电路全码仿真；既有控制器/数组没有被修改。

理想栅驱的极性另行明确，不能把高有效请求直接接PMOS栅极：

`G_PMOS = VDD − EH`，`G_NMOS = EL`。

EH=EL=0时，两只pass管都关断；EH=EL=1禁止。参考栅边沿以20 ps为本组
理想边界种子，实际参考MOS、电容、参考阻抗及注入仍由PDK电路求解。

## 3 采样和底板恢复统一

中点初态 CODE=128，物理选择为：

| 请求 | 八位字 |
| --- | --- |
| PH | `01111111` |
| PL | `10000000` |
| NH | `10000000` |
| NL | `01111111` |

初态两侧加权底板共模相等，第一次比较直接看到采样差分。
不增加底板VCM第三支路，也不把当前顶板采样改成底板采样。

以下是**待实现适配边界的合同**，不是现有控制器已经具备的物理采样动作：

| 阶段 | Bootstrap | 物理底板与适配边界 |
| --- | --- | --- |
| 初次运行 | 先经过一个完整SAMPLE高相 | 以中点初态建立；此前读取无效 |
| SAMPLE上升 | 开始接通输入 | 保持当前物理选择状态，取消上周期尚未执行的参考事件；不直接跟随逻辑输出全关 |
| SAMPLE上升后2 ns | 输入已进入采样相 | 发中点恢复请求；变化bank先断后通，再进入上述中点字 |
| 采样剩余时间 | 保持跟踪 | 底板保持中点，不让整个有效阵列浮空采样 |
| SAMPLE下降 | 隔离输入、开始保持 | 继续保持中点；屏蔽原始选择信号刚退出初始化时的全零空档 |
| 原始中点请求有效 | 已隔离 | 无突变交接给交叉映射后的原生选择；后续逐位换轨仍遵守非交叠 |
| 下一次SAMPLE | 重新采样 | 重复上述恢复；采样打断时旧待执行事件不得污染下一帧 |

变化bank实际参考命令的关断间隔至少100 ps，同时尊重原生选择信号已有的
非交叠。不能让采样覆盖路径绕过BBM，也不能未经测量把两段延迟机械相加后
还声称总dead time仍是100 ps。采样/参考适配属于**显式理想栅驱边界**，
不向原生SAR控制器新增握手状态，不读取Vin来预先算码，不替代真实比较器。

## 4 时序和模型边界

只保留一条外部SAMPLE，100 ns周期；采样边沿选100 ps以保留模拟链已有
PHI边沿。使用Spectre pulse的delay=1 ns、width=39.9 ns、rise/fall=100 ps，
两次50%穿越约1.05/41.05 ns，采集间隔为40 ns。参考恢复请求约3.05 ns，
变化bank的新轨最早约3.15 ns开始接通。

现有原生控制器测试台用20 ps采样边沿，本组统一成100 ps后必须重新联测；
不能直接照搬它的70.31 ns末位时刻。CMP_CLK仍由原生本地循环产生，不保留
原参考表征台的200-MHz比较/锁存时钟、独立PREPARE或HOLD_START。
固定读取窗口仍是95–99 ns；没有EOC不能推断任意部分码都有效。

原生quiet/valid/write/bbm的RC种子暂不改变。实际参考建立时间及比较器
复位间隔必须在合龙波形中测量，不能用旧固定5-ns实验代替。

合龙时移除 `sar8a_plant` 对TOPP/TOPN的理想电压贡献，以及旧VA SAR和理想
符号比较器。输入测试源可以理想，但不得在真实CDAC上并联一个理想DAC，
也不得从Vin直接计算输出字。PVT、MC/物理噪声和实际驱动功耗暂不展开。

## 5 已清点的证据和冻结边界

本轮通过只读Bridge再次核对21个控制器cell＋Bootstrap＋StrongARM：
23个OA模块的连接、几何和端口与选定记录相同。库路径和技术绑定均核对。
控制器/StrongARM来源固定为 `tb_sar8s_strongarm/simple_v2/input.scs`；
模拟链来源固定为 `output/cdac8_uniform_scale/decks/control_m3.scs`。
冻结指纹记录15份源文件，不提交其PDK include正文或完整原生导出。

3×已有五输入及一次细步长复核，共6个成功且满足其有界门槛的运行：
它们仍是旧固定时序/理想比较器/理想栅驱条件。最坏端口约0.982777 V，
距当前0.99-V模型检查线约7.223 mV；最大比较前误差约0.521631 mV。
这些只作为选用3×的已有依据，不证明新异步整机或所有输入/应力通过。

本次四个定向检查通过：3×选型、256码映射/电荷关系、栅压极性/禁止直通、
采样和转换起点一致。源文件哈希检查通过，23份OA读回一致。
没有改旧原理图、没有新建整机、没有新仿真；接口适配器仍明确标记为未实现。
